이 가이드는 bntpool.com에서 풀 채굴을 할지, 자신의 노드에서 솔로 채굴을 할지 결정하도록 돕습니다. 자신의 해시레이트로 혼자 얼마나 많은 블록을 찾을 수 있는지 계산하고, 풀이 이를 꾸준한 지급으로 바꾸는 방식과 seine으로 두 방식을 설정하는 방법을 알아봅니다.

## Blocknet을 풀에서 채굴할까요, 솔로로 채굴할까요?

<Answer>
두 방식의 계산은 같습니다. 네트워크 해시레이트에서 차지하는 비율이 블록의 기대 몫을 결정합니다. bntpool.com에서는 풀이 찾는 각 블록의 일부를 받으므로 풀이 블록을 찾을 때마다 꾸준히 보상이 들어옵니다. 솔로에서는 직접 발견한 블록의 전체 보상을 가지므로 자체 노드를 운영하는 대규모 채굴에 적합합니다.
</Answer>

대부분의 채굴자에게 bntpool.com은 쉽게 시작할 수 있는 곳입니다. Seine의 기본 풀이어서 주소 외에는 설정할 것이 없고 노드를 운영하거나 동기화할 필요도 없습니다. 솔로 채굴도 완전히 지원합니다. Seine의 daemon 모드는 자신의 Blocknet 노드에서 직접 채굴합니다. 아래에서 자신의 하드웨어에 어떤 방식이 맞는지 판단하는 방법을 설명합니다.

## 솔로 채굴로 얼마나 많은 블록을 찾을 수 있나요?

<Answer>
Blocknet은 5분마다 한 블록, 하루 288블록을 목표로 합니다. 혼자 채굴하면 하루에 288 × (자신의 해시레이트 ÷ 네트워크 해시레이트)개의 블록을 기대할 수 있습니다. 하루를 이 수로 나누면 블록 사이의 평균 시간이 됩니다. 실시간 네트워크 해시레이트는 bntpool.com 대시보드에서 확인하세요.
</Answer>

이 식이 성립하는 이유는 Blocknet이 전체 네트워크에서 평균 300초마다 블록을 찾도록 난이도를 조정하고, 블록 난이도가 성공까지 필요한 예상 해시 횟수와 관련되기 때문입니다. 모든 해시의 성공 확률이 같으므로, 전체 해시 중 자신의 머신이 계산하는 비율이 발견할 것으로 기대되는 블록의 비율입니다.

두 가지 수치가 필요합니다.

- **자신의 해시레이트.** Seine은 채굴 중 대시보드에 표시하고, 풀에서 채굴한 뒤에는 [통계 페이지](/stats)에서도 볼 수 있습니다.
- **네트워크 해시레이트.** [bntpool.com 대시보드](/)의 Pool Hashrate 카드 옆 Network Hashrate 카드에서 확인합니다. 둘 다 시간에 따라 변하므로 계산할 때 확인하세요.

발견한 각 블록에는 해당 월의 블록 보상이 지급됩니다. [블록 보상 일정](/blog/ko/blocknet-block-reward-schedule/)에서 월별 보상을 확인할 수 있습니다.

## 계산 예시

<Note>
아래 수치는 계산을 설명하기 위해 고른 가상의 어림수이며 실시간 값이 아닙니다. 자신의 추정에는 대시보드의 현재 네트워크 해시레이트를 사용하세요.
</Note>

네트워크가 50,000 H/s라고 가정하겠습니다. Seine이 AMD EPYC Zen 5 서버 한 대에서 측정한 값과 비슷한 50 H/s 장비는 네트워크의 0.1%를 차지합니다. 이 장비와 더 큰 두 운영 규모가 혼자 채굴할 때의 결과는 다음과 같습니다.

| 자신의 해시레이트(예시) | 네트워크 비율 | 하루 기대 블록 수 | 블록 사이 평균 시간 |
|---|---|---|---|
| 50 H/s | 0.1% | 0.288 | 약 83시간(3.5일) |
| 500 H/s | 1% | 2.88 | 약 8.3시간 |
| 5,000 H/s | 10% | 28.8 | 약 50분 |

이제 50 H/s 장비를 총 5,000 H/s인 풀에 연결합니다. 풀은 하루 약 28.8블록, 평균 50분마다 한 블록을 찾고, 장비는 풀 작업의 1%를 기여하므로 각 블록의 1%를 받습니다. 인정되는 작업량은 똑같이 하루 0.288블록입니다. 달라지는 것은 보상의 형태입니다. 솔로에서는 며칠마다 전체 블록 하나를 받지만 풀에서는 약 50분마다 작은 몫을 받습니다.

표는 솔로 채굴이 대규모 운영에 적합한 이유도 보여 줍니다. 5,000 H/s의 솔로 채굴자는 같은 크기의 풀만큼 자주 블록을 찾아 혼자서도 꾸준한 수익을 얻습니다.

자신의 하드웨어에 대해 하루 블록 수를 BNT로 환산하고 날짜가 명시된 실제 풀 데이터 예시를 보려면 [Blocknet 채굴 보상 추정 방법](/blog/ko/estimate-blocknet-mining-rewards/)을 참고하세요.

## 풀의 지급이 더 꾸준한 이유는 무엇인가요?

bntpool.com은 참여자의 해시레이트를 합쳐 단일 장비보다 훨씬 자주 블록을 찾습니다. 각 블록의 보상은 PPLNS에 따라 발견에 기여한 채굴자들 사이에 분배됩니다. 풀은 블록 발견 전 6시간을 살펴보고 각 채굴자의 셰어 난이도에 비례해 보상을 나눕니다.

실제로 다음과 같은 효과가 있습니다.

- **모든 블록에서 수익 발생.** 셰어가 6시간 구간에 있는 한 풀이 찾는 각 블록의 몫을 받습니다. [블록 페이지](/blocks)에서 확인할 수 있습니다.
- **자동 지급.** 블록이 60블록 깊이에 도달하면 자신의 몫이 확정 잔액으로 옮겨지고, 0.1 BNT에 도달하면 주소로 송금됩니다. 송금 내역은 [지급 페이지](/payouts)에 표시됩니다.
- **재시작해도 이어지는 기록.** 이미 제출한 셰어는 6시간 동안 구간에 남으므로 재부팅이나 드라이버 업데이트로 초기화되지 않습니다.
- **채굴 프로그램만 실행하면 됩니다.** 풀이 노드를 운영하고 템플릿을 만들며 블록을 제출합니다. 여러 장비에서 하나의 주소나 Blocknet ID `@name`으로 채굴할 수 있습니다.

[PPLNS 보상 가이드](/blog/ko/how-pplns-payouts-work/)에서 계산 예시와 함께 분배 과정을 설명합니다. 현재 보상 설정은 풀의 [Get Started 페이지](/start)에 나와 있습니다.

## Blocknet을 솔로 채굴하는 이유는 무엇인가요?

솔로 채굴에서는 모든 과정을 직접 관리합니다. 자신의 노드가 각 블록 템플릿을 만들고 모든 블록을 직접 검증하며, 발견한 블록의 전체 보상이 바로 노드의 지갑으로 지급됩니다.

자신의 해시레이트로 블록을 자주 찾을 때 가장 적합합니다. 위 예시에서 네트워크의 10%를 가진 운영은 약 50분마다 블록을 찾아 풀처럼 정기적으로 보상을 받습니다. 지갑이나 다른 서비스를 위해 이미 Blocknet 노드를 운영한다면 그 위에 채굴 프로그램을 추가하면 됩니다.

Seine은 이 모드도 지원하도록 만들어졌습니다. 노드의 블록 템플릿으로 채굴하며, 재시작 등으로 노드가 템플릿을 잊었을 때는 해결한 전체 블록을 다시 제출하여 발견한 블록이 체인에 도달하도록 합니다.

## Seine으로 솔로 채굴을 어떻게 설정하나요?

1. **Blocknet 노드를 설치하고 동기화합니다.** `blocknet` 래퍼로 다음을 실행합니다.

   ```sh
   blocknet install latest
   blocknet start mainnet
   ```

   노드의 API 쿠키가 `~/.config/bnt/data/mainnet/api.cookie`에 기록됩니다. 초기 동기화를 줄이기 위해 bntpool.com은 [체크포인트 페이지](/checkpoints)에 `checkpoints.dat` 파일을 제공합니다. [체크포인트로 Blocknet 노드 동기화하기](/blog/ko/blocknet-checkpoints-fast-sync/)에서 사용 방식을 설명합니다.
2. **동기화가 끝날 때까지 기다립니다.** 노드의 `[sync] progress` 메시지가 100%에 도달합니다. 노드는 체인을 따라잡은 뒤에만 블록 템플릿을 제공합니다.
3. **Seine을 daemon 모드로 실행합니다.**

   ```sh
   ./seine --mode daemon
   ```

   사용자 지정 노드 구성이라면 API와 쿠키를 직접 지정합니다.

   ```sh
   ./seine --mode daemon --api-url http://127.0.0.1:8332 --cookie /path/to/api.cookie
   ```

[솔로 채굴 가이드](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)는 지갑 비밀번호와 사용자 지정 구성을, [seine 채굴 가이드](https://seineminer.com/ko/blog/how-to-mine-blocknet/)는 다운로드와 첫 셰어 제출을 설명합니다. Windows, macOS, Linux용 [seine을 내려받을 수 있습니다](https://seineminer.com/ko/#download).

## 어떤 방식을 선택해야 하나요?

자신의 해시레이트와 [대시보드](/)의 현재 네트워크 해시레이트로 계산한 뒤 평균 블록 간격을 확인하세요.

- **bntpool.com에서 시작하세요.** 데스크톱, 노트북 또는 몇 대의 서버를 쓰거나, 노드 없이 꾸준한 지급을 원할 때 적합합니다. Seine을 실행하고 주소나 `@name`을 입력한 뒤 기본 풀을 선택하세요.
- **솔로로 채굴하세요.** 네트워크의 큰 비중을 차지해 혼자서도 블록을 자주 찾고, 동기화된 자체 노드를 이미 운영하거나 운영하려는 경우에 적합합니다.

Seine에서는 선택을 쉽게 바꿀 수 있습니다. 풀 채굴과 daemon 모드는 같은 프로그램을 사용하므로 하드웨어가 늘어나면 플래그 하나와 재시작으로 전환할 수 있습니다. 풀에서 채굴하면서 로컬 노드도 실행하면 seine이 풀 잔액 옆에 노드 지갑 잔액도 보여 줍니다.

<Note>
[blocknetcrypto.com](https://blocknetcrypto.com/#faraday)에 따르면 Blocknet은 2027년 2월 16일 무렵 Faraday라는 네트워크 업그레이드를 계획하고 있습니다. 작업 증명을 변경할 예정입니다. Seine을 최신으로 유지하세요. 시작할 때와 12시간마다 새 릴리스를 확인합니다.
</Note>
