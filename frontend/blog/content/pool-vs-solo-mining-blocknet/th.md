คู่มือนี้ช่วยเลือกว่าจะขุด Blocknet บน bntpool.com หรือ solo กับโหนดของตนเอง คุณจะคำนวณว่า hashrate ของคุณพบบล็อกเองได้เท่าไร เห็นว่าพูลเปลี่ยนเป็นการจ่ายต่อเนื่องอย่างไร และเรียนรู้การตั้งค่าทั้งสองแบบด้วย seine

## ควรขุด Blocknet กับพูลหรือ solo?

<Answer>
ทั้งสองใช้หลักคำนวณเดียวกัน: สัดส่วน hashrate ในเครือข่ายกำหนดสัดส่วนบล็อกของคุณ บน bntpool.com คุณได้ส่วนแบ่งจากทุกบล็อกที่พูลพบ การจ่ายจึงสม่ำเสมอตามการพบบล็อก ส่วน solo เก็บรางวัลเต็มของแต่ละบล็อกที่คุณพบ เหมาะกับระบบขุดขนาดใหญ่ที่เปิดโหนดของตนเอง
</Answer>

สำหรับนักขุดส่วนใหญ่ bntpool.com เป็นจุดเริ่มที่ง่าย เป็นพูลเริ่มต้นของ seine จึงตั้งค่าเพียงที่อยู่ ไม่ต้องเปิดหรือซิงก์โหนด Solo ก็รองรับเต็มที่เช่นกัน: seine มีโหมด daemon ที่ขุดตรงกับโหนด Blocknet ของคุณ ส่วนที่เหลือของคู่มือช่วยดูว่าแบบไหนเหมาะกับฮาร์ดแวร์

## คุณจะพบบล็อกเองได้เท่าไร?

<Answer>
Blocknet ตั้งเป้าหนึ่งบล็อกทุกห้านาที หรือ 288 บล็อกต่อวัน เมื่อขุดคนเดียว คาดหมายได้ 288 × (hashrate ของคุณ ÷ hashrate เครือข่าย) บล็อกต่อวัน นำหนึ่งวันหารด้วยจำนวนนี้เพื่อหาเวลาเฉลี่ยระหว่างบล็อกของคุณ ดู hashrate เครือข่ายปัจจุบันได้บนแดชบอร์ด bntpool.com
</Answer>

สูตรนี้ใช้ได้เพราะ Blocknet ปรับความยากให้ทั้งเครือข่ายพบบล็อกเฉลี่ยทุก 300 วินาที ความยากบล็อกใกล้เคียงจำนวน hash ที่คาดว่าต้องลองก่อนสำเร็จ แต่ละ hash มีโอกาสเท่ากัน สัดส่วน hash ที่มาจากเครื่องคุณจึงเป็นสัดส่วนบล็อกที่คาดว่าจะพบ

ต้องมีสองค่า:

- **Hashrate ของคุณ** seine แสดงบนแดชบอร์ดขณะขุด และ[หน้าสถิติ](/stats)ของพูลแสดงหลังคุณขุดกับพูล
- **Hashrate เครือข่าย** [แดชบอร์ด bntpool.com](/) แสดงใน Network Hashrate ข้าง Pool Hashrate ทั้งสองเปลี่ยนตามเวลา จึงควรตรวจตอนคำนวณ

ทุกบล็อกที่คุณพบจ่ายตามรางวัลของเดือนนั้น [ตารางรางวัลบล็อก](/blog/th/blocknet-block-reward-schedule/) แสดงรางวัลรายเดือน

## ตัวอย่างการคำนวณ

<Note>
ตัวเลขต่อไปนี้เป็นค่ากลมสมมติเพื่อแสดงวิธีคิด ไม่ใช่ข้อมูลสด ใช้ hashrate เครือข่ายปัจจุบันจากแดชบอร์ดเมื่อต้องการประมาณของคุณเอง
</Note>

สมมติเครือข่ายมี 50,000 H/s เครื่องหนึ่งมี 50 H/s ใกล้กับที่ seine วัดได้บน AMD EPYC Zen 5 หนึ่งเซิร์ฟเวอร์ จึงถือ 0.1% ของเครือข่าย ผลที่เครื่องนี้และระบบใหญ่กว่าอีกสองแบบคาดว่าจะพบเมื่อขุดคนเดียวคือ:

| Hashrate ของคุณ (ตัวอย่าง) | สัดส่วนเครือข่าย | บล็อกที่คาดหมายต่อวัน | เวลาเฉลี่ยระหว่างบล็อก |
|---|---|---|---|
| 50 H/s | 0.1% | 0.288 | ประมาณ 83 ชั่วโมง (3.5 วัน) |
| 500 H/s | 1% | 2.88 | ประมาณ 8.3 ชั่วโมง |
| 5,000 H/s | 10% | 28.8 | ประมาณ 50 นาที |

ย้ายเครื่อง 50 H/s ไปพูลที่มีรวม 5,000 H/s พูลพบบล็อกประมาณ 28.8 บล็อกต่อวัน หรือเฉลี่ยทุก 50 นาที เครื่องมีสัดส่วนงาน 1% จึงได้ 1% ของแต่ละบล็อก งานที่นับยังเท่ากับ 0.288 บล็อกต่อวัน แต่ได้รับเป็นส่วนเล็กประมาณทุก 50 นาที แทนหนึ่งบล็อกเต็มทุกหลายวันแบบ solo

ตารางยังแสดงเหตุผลที่ solo เหมาะกับระบบใหญ่ ที่ 5,000 H/s นักขุด solo พบบล็อกบ่อยเท่าพูลขนาดเดียวกัน รายได้จึงสม่ำเสมอได้ด้วยตัวเอง

หากต้องการแปลงบล็อกต่อวันเป็น BNT สำหรับฮาร์ดแวร์ของคุณ พร้อมตัวอย่างระบุวันที่จากข้อมูลจริงของพูล อ่าน[วิธีประมาณรางวัลขุด Blocknet](/blog/th/estimate-blocknet-mining-rewards/)

## ทำไมพูลจ่ายสม่ำเสมอกว่า?

bntpool.com รวม hashrate ของทุกคน จึงพบบล็อกบ่อยกว่าเครื่องเดียวมาก รางวัลแบ่งให้ผู้ร่วมส่งงานด้วย PPLNS: นับหกชั่วโมงก่อนบล็อกแล้วแบ่งตามสัดส่วนค่าความยาก share ของแต่ละคน

สิ่งที่คุณได้รับในทางปฏิบัติคือ:

- **ได้จากทุกบล็อก** ตราบที่ share อยู่ในช่วงหกชั่วโมง คุณได้ส่วนแบ่งทุกบล็อกที่พูลพบ ติดตามใน[หน้าบล็อก](/blocks)
- **จ่ายอัตโนมัติ** เมื่อบล็อกลึก 60 บล็อก ส่วนแบ่งย้ายเป็นยอดยืนยันแล้ว และส่งให้เมื่อถึง 0.1 BNT ดูรายการที่ส่งใน[หน้าการจ่าย](/payouts)
- **ต่อเนื่องแม้รีสตาร์ต** Share ที่ส่งแล้วอยู่หกชั่วโมง การรีบูตหรืออัปเดตไดรเวอร์จึงไม่รีเซ็ตส่วนของคุณ
- **เปิดแค่โปรแกรมขุด** พูลเปิดโหนด สร้างเทมเพลตและส่งบล็อก คุณขุดจากหลายเครื่องไปที่อยู่เดียวหรือ Blocknet ID `@name` ได้

[คู่มือจ่าย PPLNS](/blog/th/how-pplns-payouts-work/) อธิบายการแบ่งทีละขั้นพร้อมตัวอย่าง [หน้า Get Started](/start) แสดงการตั้งค่าจ่ายปัจจุบัน

## ทำไมจึงเลือกขุด Blocknet แบบ solo?

Solo ให้คุณควบคุมทุกส่วน โหนดของคุณสร้างเทมเพลตและตรวจทุกบล็อกเอง แต่ละบล็อกที่พบจ่ายรางวัลเต็มตรงเข้ากระเป๋าโหนด

เหมาะที่สุดเมื่อ hashrate ของคุณพบบล็อกบ่อย ตัวอย่างด้านบน ระบบที่มี 10% ของเครือข่ายพบบล็อกประมาณทุก 50 นาที การจ่าย solo จึงสม่ำเสมอเท่าพูล หากเปิดโหนด Blocknet สำหรับกระเป๋าหรือบริการอื่นอยู่แล้ว ก็เพิ่มโปรแกรมขุดเข้ากับโหนดนั้นได้

seine รองรับโหมดนี้โดยตรง ใช้เทมเพลตจากโหนด และถ้าโหนดลืมเทมเพลต เช่นหลังรีสตาร์ต seine จะส่งบล็อกที่แก้สำเร็จทั้งบล็อกอีกครั้ง เพื่อให้บล็อกที่พบยังเข้าสู่เชน

## ตั้งค่า solo ด้วย seine อย่างไร?

1. **ติดตั้งและซิงก์โหนด Blocknet** ใช้ตัวจัดการ `blocknet` แล้วรัน:

   ```sh
   blocknet install latest
   blocknet start mainnet
   ```

   โหนดเขียน API cookie ที่ `~/.config/bnt/data/mainnet/api.cookie` เพื่อย่นเวลาซิงก์ครั้งแรก bntpool.com เผยแพร่ `checkpoints.dat` ใน[หน้า checkpoints](/checkpoints) [คู่มือซิงก์โหนดด้วย checkpoints](/blog/th/blocknet-checkpoints-fast-sync/) อธิบายวิธีใช้
2. **รอซิงก์เสร็จ** ข้อความ `[sync] progress` จะถึง 100% โหนดให้เทมเพลตบล็อกเมื่อไล่ทันเชนแล้วเท่านั้น
3. **เริ่ม seine ในโหมด daemon**

   ```sh
   ./seine --mode daemon
   ```

   หากใช้โครงสร้างโหนดแบบกำหนดเอง ระบุ API และ cookie:

   ```sh
   ./seine --mode daemon --api-url http://127.0.0.1:8332 --cookie /path/to/api.cookie
   ```

[คู่มือ solo](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md) อธิบายรหัสผ่านกระเป๋าและการตั้งค่าเฉพาะ ส่วน[คู่มือขุดด้วย seine](https://seineminer.com/th/blog/how-to-mine-blocknet/) อธิบายดาวน์โหลดและ share แรก [ดาวน์โหลด seine](https://seineminer.com/th/#download) ได้สำหรับ Windows, macOS หรือ Linux

## ควรเลือกแบบไหน?

ใช้สูตรกับ hashrate ของคุณและ hashrate เครือข่ายปัจจุบันจาก[แดชบอร์ด](/) แล้วดูเวลาเฉลี่ยระหว่างบล็อก

- **เริ่มกับ bntpool.com** หากขุดบนเดสก์ท็อป แล็ปท็อป หรือเซิร์ฟเวอร์ไม่กี่เครื่อง หรือต้องการการจ่ายสม่ำเสมอโดยไม่เปิดโหนด เปิด seine วางที่อยู่หรือ `@name` แล้วยอมรับพูลเริ่มต้น
- **ขุด solo** หากระบบของคุณมีสัดส่วนเครือข่ายมากจนพบบล็อกเองบ่อย และเปิดหรืออยากเปิดโหนดที่ซิงก์แล้วของตนเอง

seine ทำให้เปลี่ยนใจภายหลังได้ง่าย พูลกับโหมด daemon ใช้ไฟล์เดียวกัน เมื่อเพิ่มฮาร์ดแวร์จึงสลับได้ด้วยแฟล็กเดียวและรีสตาร์ต หากเปิดโหนดในเครื่องระหว่างขุดกับพูล seine ยังแสดงยอดกระเป๋าโหนดข้างยอดพูลด้วย

<Note>
Blocknet วางแผนอัปเกรดเครือข่ายชื่อ Faraday ราว 16 กุมภาพันธ์ 2027 ตาม [blocknetcrypto.com](https://blocknetcrypto.com/#faraday) โดยวางแผนเปลี่ยน proof of work อัปเดต seine อยู่เสมอ โปรแกรมตรวจรุ่นใหม่เมื่อเปิดและทุก 12 ชั่วโมง
</Note>
