本指南幫助你決定是在 bntpool.com 上挖 Blocknet，還是用自己的節點單獨挖礦。你將算出自己的算力單獨能找到多少區塊，了解礦池如何把它變成穩定持續的收益，並學會用 seine 設定這兩種方式。

## Blocknet 應該用礦池挖還是單獨挖？

<Answer>
兩者遵循同樣的計算方式：你占全網算力的比例決定你能獲得的區塊比例。在 bntpool.com 上，礦池找到的每個區塊你都能分到一部分，因此隨著礦池不斷出塊，收益會穩定入帳。單獨挖礦時，你找到的每個區塊的全部獎勵都歸你，適合執行自己節點的大型礦場。
</Answer>

對大多數礦工來說，bntpool.com 是最容易上手的選擇。它是 seine 的預設礦池，除了填寫地址之外無需任何設定，也不需要執行或同步節點。單獨挖礦同樣獲得完整支援：seine 提供 daemon 模式，可以直接對接你自己的 Blocknet 節點挖礦。本指南接下來會說明如何判斷哪種方式適合你的硬體。

## 單獨挖礦能找到多少區塊？

<Answer>
Blocknet 的目標是每五分鐘出一個塊，即每天 288 個區塊。單獨挖礦時，你每天預期能找到 288 × (你的算力 ÷ 全網算力) 個。用一天除以這個數，就得到你平均多久找到一個區塊。全網即時算力可以在 bntpool.com 儀表板上查看。
</Answer>

這個公式成立，是因為 Blocknet 會調整難度，使全網平均每 300 秒找到一個區塊，而區塊的難度大約就是全網在成功之前預期要嘗試的雜湊次數。每次雜湊成功的機率都相同，所以全網雜湊中來自你電腦的比例，就是你預期能找到的區塊比例。

你需要兩個數字：

- **你的算力。** seine 在挖礦時會在儀表板上顯示它；你在礦池挖過礦之後，礦池的[統計頁面](/stats)也會顯示。
- **全網算力。** [bntpool.com 儀表板](/)上的 Network Hashrate（全網算力）卡片會顯示它，旁邊是 Pool Hashrate（礦池算力）卡片。兩者都會隨時間變化，所以計算時請查看當時的數值。

你找到的每個區塊都按當月的區塊獎勵支付。[區塊獎勵時程表](/blog/zh-hant/blocknet-block-reward-schedule/)列出了每個月的獎勵。

## 計算範例

<Note>
下面的數字是為了示範計算方法而假設的整數，並非即時數值。估算你自己的情況時，請使用儀表板上目前的全網算力。
</Note>

假設全網算力為 50,000 H/s。一台 50 H/s 的礦機（大約是 seine 在一台 AMD EPYC Zen 5 伺服器上實測的算力）占全網的 0.1%。下表是這台礦機與兩個更大的礦場單獨挖礦時能找到的區塊數：

| 你的算力（範例） | 占全網比例 | 每天預期區塊數 | 平均出塊間隔 |
|---|---|---|---|
| 50 H/s | 0.1% | 0.288 | 約 83 小時（3.5 天） |
| 500 H/s | 1% | 2.88 | 約 8.3 小時 |
| 5,000 H/s | 10% | 28.8 | 約 50 分鐘 |

現在把這台 50 H/s 的礦機放到一個總算力同樣為 5,000 H/s 的礦池裡。礦池每天約找到 28.8 個區塊，平均每 50 分鐘一個，這台礦機占礦池工作量的 1%，就能獲得每個區塊的 1%。計入的工作量同樣是每天 0.288 個區塊，改變的是入帳方式：大約每 50 分鐘入帳一小部分，而單獨挖礦時則是每隔幾天入帳一個完整區塊。

這張表也說明了為什麼單獨挖礦適合大型礦場。在 5,000 H/s 時，單獨礦工找到區塊的頻率與同等規模的礦池一樣，因此它本身的收入就很穩定。

要把每天的區塊數換算成你自己的硬體能挖到的 BNT，並查看根據礦池即時資料、註明日期的範例，請參閱[如何估算 Blocknet 挖礦收益](/blog/zh-hant/estimate-blocknet-mining-rewards/)。

## 為什麼礦池的收益更穩定？

bntpool.com 匯集了所有在其上挖礦的礦工的算力，因此找到區塊的頻率遠高於任何一台礦機。每個區塊的獎勵會採用 PPLNS 方式，分給為找到該區塊出過力的礦工：礦池回看該區塊之前的六小時，依每位礦工份額難度的比例分配獎勵。

這對你有幾點實際好處：

- **每個區塊都有收益。** 只要你的份額還在六小時區間內，礦池找到的每個區塊你都能分到一部分。你可以在[區塊頁面](/blocks)上看到這些區塊陸續出現。
- **自動支付。** 區塊達到 60 個區塊深度後，你的那部分會轉入已確認收益，餘額達到 0.1 BNT 時礦池會把它發送到你的地址。已發送的款項列在[支付頁面](/payouts)上。
- **重新啟動不受影響。** 你已經提交的份額會在區間中保留六小時，所以重新開機或更新驅動程式不會讓你的進度歸零。
- **只需執行挖礦軟體。** 礦池負責執行節點、建立區塊範本並提交區塊。你可以讓多台礦機挖到同一個地址，或挖到一個 Blocknet ID `@name`。

[PPLNS 收益指南](/blog/zh-hant/how-pplns-payouts-work/)一步步說明了分配過程，並附有另外的計算範例。礦池的 [Get Started 頁面](/start)列出了目前的支付設定。

## 為什麼要單獨挖 Blocknet？

單獨挖礦讓整個過程都由你掌控。你自己的節點建立每個區塊範本並親自驗證每個區塊，你找到的每個區塊都會把全部獎勵直接支付到節點的錢包。

當你的算力能頻繁找到區塊時，單獨挖礦最為合適。在上面的範例中，占全網 10% 的礦場大約每 50 分鐘就能找到一個區塊，因此單獨挖礦的收益與同等規模的礦池一樣規律。如果你已經為錢包或其他服務執行著 Blocknet 節點，單獨挖礦只需在此基礎上加上挖礦軟體。

seine 同樣為這種模式做好了準備。它依據節點的區塊範本挖礦；如果節點遺失了某個範本（例如重新啟動之後），seine 會自動重新提交完整的已解出區塊，確保找到的區塊仍然能上鏈。

## 如何用 seine 設定單獨挖礦？

1. **安裝並同步 Blocknet 節點。** 使用 `blocknet` 包裝工具，執行：

   ```sh
   blocknet install latest
   blocknet start mainnet
   ```

   這會把節點的 API cookie 寫入 `~/.config/bnt/data/mainnet/api.cookie`。為了縮短首次同步時間，bntpool.com 在其[檢查點頁面](/checkpoints)上發布了用於快速初始同步的 `checkpoints.dat` 檔案；[用檢查點快速同步 Blocknet 節點](/blog/zh-hant/blocknet-checkpoints-fast-sync/)說明了節點如何使用它。
2. **等待同步完成。** 節點的 `[sync] progress` 訊息會達到 100%。節點只有在追上鏈之後才會提供區塊範本。
3. **以 daemon 模式啟動 seine。**

   ```sh
   ./seine --mode daemon
   ```

   如果節點目錄是自訂的，請自行為 seine 指定 API 與 cookie：

   ```sh
   ./seine --mode daemon --api-url http://127.0.0.1:8332 --cookie /path/to/api.cookie
   ```

[單獨挖礦指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)說明了錢包密碼與自訂設定，[seine 挖礦指南](https://seineminer.com/zh-hant/blog/how-to-mine-blocknet/)說明了如何下載 seine 並獲得第一批份額。你可以[下載 seine](https://seineminer.com/zh-hant/#download)，支援 Windows、macOS 與 Linux。

## 應該選哪一種？

用你自己的算力與[儀表板](/)上目前的全網算力套用公式，然後看看平均出塊間隔。

- **從 bntpool.com 開始**：如果你用桌上型電腦、筆記型電腦或少量伺服器挖礦，或者希望不執行節點就獲得穩定收益。執行 seine，貼上你的地址或 `@name`，接受預設礦池即可。
- **單獨挖礦**：如果你的礦場占全網算力的比例很大，自己就能頻繁找到區塊，並且你已經執行或打算執行自己的已同步節點。

seine 讓你隨時可以重新選擇。礦池挖礦與 daemon 模式使用同一個下載檔，隨著硬體規模擴大，只需一個參數加一次重新啟動就能切換。如果你在礦池挖礦的同時執行著本機節點，seine 還會在礦池餘額旁邊顯示節點錢包的餘額。

<Note>
根據 [blocknetcrypto.com](https://blocknetcrypto.com/#faraday)，Blocknet 計畫在 2027-02-16 前後進行名為 Faraday 的網路升級，屆時工作量證明演算法預計會改變。請保持 seine 為最新版本：它會在啟動時以及每 12 小時檢查一次新版本。
</Note>
