本指南帮助你决定是在 bntpool.com 上挖 Blocknet，还是用自己的节点单独挖矿。你将算出自己的算力单独能找到多少区块，了解矿池如何把它变成稳定持续的收益，并学会用 seine 设置这两种方式。

## Blocknet 应该用矿池挖还是单独挖？

<Answer>
两者遵循同样的计算方式：你占全网算力的比例决定你能获得的区块比例。在 bntpool.com 上，矿池找到的每个区块你都能分到一部分，因此随着矿池不断出块，收益会稳定到账。单独挖矿时，你找到的每个区块的全部奖励都归你，适合运行自己节点的大型矿场。
</Answer>

对大多数矿工来说，bntpool.com 是最容易上手的选择。它是 seine 的默认矿池，除了填写地址之外无需任何设置，也不需要运行或同步节点。单独挖矿同样得到完整支持：seine 提供 daemon 模式，可以直接对接你自己的 Blocknet 节点挖矿。本指南接下来会说明如何判断哪种方式适合你的硬件。

## 单独挖矿能找到多少区块？

<Answer>
Blocknet 的目标是每五分钟出一个块，即每天 288 个区块。单独挖矿时，你每天预期能找到 288 × (你的算力 ÷ 全网算力) 个。用一天除以这个数，就得到你平均多久找到一个区块。全网实时算力可以在 bntpool.com 仪表盘上查看。
</Answer>

这个公式成立，是因为 Blocknet 会调整难度，使全网平均每 300 秒找到一个区块，而区块的难度大约就是全网在成功之前预期要尝试的哈希次数。每次哈希成功的概率都相同，所以全网哈希中来自你机器的比例，就是你预期能找到的区块比例。

你需要两个数字：

- **你的算力。** seine 在挖矿时会在仪表盘上显示它；你在矿池挖过矿之后，矿池的[统计页面](/stats)也会显示。
- **全网算力。** [bntpool.com 仪表盘](/)上的 Network Hashrate（全网算力）卡片会显示它，旁边是 Pool Hashrate（矿池算力）卡片。两者都会随时间变化，所以计算时请查看当时的数值。

你找到的每个区块都按当月的区块奖励支付。[区块奖励时间表](/blog/zh-hans/blocknet-block-reward-schedule/)列出了每个月的奖励。

## 计算示例

<Note>
下面的数字是为了演示计算方法而假设的整数，并非实时数值。估算你自己的情况时，请使用仪表盘上当前的全网算力。
</Note>

假设全网算力为 50,000 H/s。一台 50 H/s 的矿机（大约是 seine 在一台 AMD EPYC Zen 5 服务器上实测的算力）占全网的 0.1%。下表是这台矿机和两个更大的矿场单独挖矿时能找到的区块数：

| 你的算力（示例） | 占全网比例 | 每天预期区块数 | 平均出块间隔 |
|---|---|---|---|
| 50 H/s | 0.1% | 0.288 | 约 83 小时（3.5 天） |
| 500 H/s | 1% | 2.88 | 约 8.3 小时 |
| 5,000 H/s | 10% | 28.8 | 约 50 分钟 |

现在把这台 50 H/s 的矿机放到一个总算力同样为 5,000 H/s 的矿池里。矿池每天约找到 28.8 个区块，平均每 50 分钟一个，这台矿机占矿池工作量的 1%，就能获得每个区块的 1%。计入的工作量同样是每天 0.288 个区块，变化的是到账方式：大约每 50 分钟到账一小部分，而单独挖矿时则是每隔几天到账一个完整区块。

这张表也说明了为什么单独挖矿适合大型矿场。在 5,000 H/s 时，单独矿工找到区块的频率和同等规模的矿池一样，因此它自身的收入就很稳定。

要把每天的区块数换算成你自己的硬件能挖到的 BNT，并查看基于矿池实时数据、注明日期的示例，请参阅[如何估算 Blocknet 挖矿收益](/blog/zh-hans/estimate-blocknet-mining-rewards/)。

## 为什么矿池的收益更稳定？

bntpool.com 汇集了所有在其上挖矿的矿工的算力，因此找到区块的频率远高于任何一台矿机。每个区块的奖励会采用 PPLNS 方式，分给为找到该区块出过力的矿工：矿池回看该区块之前的六小时，按每位矿工份额难度的比例分配奖励。

这对你有几点实际好处：

- **每个区块都有收益。** 只要你的份额还在六小时窗口内，矿池找到的每个区块你都能分到一部分。你可以在[区块页面](/blocks)上看到这些区块陆续出现。
- **自动支付。** 区块达到 60 个区块深度后，你的那部分会转入已确认收益，余额达到 0.1 BNT 时矿池会把它发送到你的地址。已发送的款项列在[支付页面](/payouts)上。
- **重启不受影响。** 你已经提交的份额会在窗口中保留六小时，所以重启电脑或更新驱动不会让你的进度归零。
- **只需运行矿工软件。** 矿池负责运行节点、构建区块模板并提交区块。你可以让多台矿机挖到同一个地址，或挖到一个 Blocknet ID `@name`。

[PPLNS 收益指南](/blog/zh-hans/how-pplns-payouts-work/)一步步讲解了分配过程，并附有另外的计算示例。矿池的 [Get Started 页面](/start)列出了当前的支付设置。

## 为什么要单独挖 Blocknet？

单独挖矿让整个过程都由你掌控。你自己的节点构建每个区块模板并亲自验证每个区块，你找到的每个区块都会把全部奖励直接支付到节点的钱包。

当你的算力能频繁找到区块时，单独挖矿最为合适。在上面的示例中，占全网 10% 的矿场大约每 50 分钟就能找到一个区块，因此单独挖矿的收益和同等规模的矿池一样规律。如果你已经为钱包或其他服务运行着 Blocknet 节点，单独挖矿只需在此基础上加上矿工软件。

seine 同样为这种模式做好了准备。它基于节点的区块模板挖矿；如果节点丢失了某个模板（例如重启之后），seine 会自动重新提交完整的已解出区块，确保找到的区块依然能上链。

## 如何用 seine 设置单独挖矿？

1. **安装并同步 Blocknet 节点。** 使用 `blocknet` 包装工具，运行：

   ```sh
   blocknet install latest
   blocknet start mainnet
   ```

   这会把节点的 API cookie 写入 `~/.config/bnt/data/mainnet/api.cookie`。为了缩短首次同步时间，bntpool.com 在其[检查点页面](/checkpoints)上发布了用于快速初始同步的 `checkpoints.dat` 文件；[用检查点快速同步 Blocknet 节点](/blog/zh-hans/blocknet-checkpoints-fast-sync/)介绍了节点如何使用它。
2. **等待同步完成。** 节点的 `[sync] progress` 消息会达到 100%。节点只有在追上链之后才会提供区块模板。
3. **以 daemon 模式启动 seine。**

   ```sh
   ./seine --mode daemon
   ```

   如果节点目录是自定义的，请自行为 seine 指定 API 和 cookie：

   ```sh
   ./seine --mode daemon --api-url http://127.0.0.1:8332 --cookie /path/to/api.cookie
   ```

[单独挖矿指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)介绍了钱包密码和自定义设置，[seine 挖矿指南](https://seineminer.com/zh-hans/blog/how-to-mine-blocknet/)介绍了如何下载 seine 并获得第一批份额。你可以[下载 seine](https://seineminer.com/zh-hans/#download)，支持 Windows、macOS 和 Linux。

## 应该选哪一种？

用你自己的算力和[仪表盘](/)上当前的全网算力套用公式，然后看看平均出块间隔。

- **从 bntpool.com 开始**：如果你用台式机、笔记本或少量服务器挖矿，或者希望不运行节点就获得稳定收益。运行 seine，粘贴你的地址或 `@name`，接受默认矿池即可。
- **单独挖矿**：如果你的矿场占全网算力的比例很大，自己就能频繁找到区块，并且你已经运行或打算运行自己的已同步节点。

seine 让你随时可以重新选择。矿池挖矿和 daemon 模式使用同一个下载包，随着硬件规模扩大，只需一个参数加一次重启就能切换。如果你在矿池挖矿的同时运行着本地节点，seine 还会在矿池余额旁边显示节点钱包的余额。

<Note>
根据 [blocknetcrypto.com](https://blocknetcrypto.com/#faraday)，Blocknet 计划在 2027-02-16 前后进行名为 Faraday 的网络升级，届时工作量证明算法预计会改变。请保持 seine 为最新版本：它会在启动时以及每 12 小时检查一次新版本。
</Note>
