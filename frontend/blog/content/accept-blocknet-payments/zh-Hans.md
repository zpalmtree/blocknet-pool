接收 Blocknet 付款时，先向客户说明准确的 BNT 金额，在自己的钱包中确认到账，再将入账记录归入订单。本文使用 **1.25 BNT**、编号 **order-1042** 的虚构订单，依据已发布的桌面钱包 v0.22.0，截图均使用明确标注的演示数据。

## 如何接收 Blocknet 付款？

<Answer>
约定 BNT 金额和订单编号，发送指向你所控制地址的付款请求，等待已同步的钱包收到款项。核对金额和编号，检查确认状态，然后记录交易 ID，并按照与客户约定的确认规则将订单标记为已付款。
</Answer>

创建或打开钱包可参阅[桌面钱包指南](https://seineminer.com/zh-hans/blog/blocknet-desktop-wallet/)。将恢复备份与订单记录分开保存。接收客户付款不需要运行矿工程序或加入矿池。

## 确定金额并标识订单

记录订单编号、BNT 金额、收款地址和购买内容。如果以其他货币报价，请在付款前约定 BNT 金额和报价有效时间。付款链接包含请求的金额，但不会更新汇率或强制执行到期时间。

示例请求 **1.25 BNT**，备注为 **order-1042**。订单编号已经足够；收货地址等客户信息留在自己的私有订单系统中。[加密备注](https://seineminer.com/zh-hans/blog/blocknet-encrypted-memos/)随付款发送，但任何收到共享链接的人都可以阅读写在链接里的备注。

在 **Receive → Payment Request** 中填写金额和备注，选择 **Generate Payment Link**。分享前核对收款人和金额。[付款链接指南](https://seineminer.com/zh-hans/blog/blocknet-payment-links/)介绍链接格式和基于名称的收款人。对固定账单，请同时保存完整收款地址。

## 在自己的钱包中核对入账

请客户填写订单编号并保留交易 ID。节点和钱包同步完成后，打开 **History** 找到入账，核对金额和备注。付款人可以修改这两个字段，因此请求本身无法证明实际发送了什么。

保存完整交易 ID 和到账金额。不要因为同一交易出现在 Dashboard 和 History 中，或客户再次发送同一个 ID，就重复计算。应匹配具体入账，而非总余额变化；总余额可能还包括挖矿收入、其他客户的款项和自己的转账。

如果找不到款项，与客户核对完整目标地址和交易 ID，再检查同步。发送页面截图可以提供线索，但实际到账金额应由自己的收款钱包确认。

## 何时标记订单为已付款？

区分未确认的入账、已包含在区块中的交易和可以花费的资金。已发布的钱包会在普通付款所在区块之后再等待十个区块，才允许花费对应输出。[转账时间指南](https://seineminer.com/zh-hans/blog/blocknet-transfer-time/)说明计数方式和不固定的等待时间。

在客户付款前说明确认规则。简单的手动流程可以等到对应入账可花费后再交付。仅看到入账金额不代表检查已经完成。区块产生间隔有变化，不要根据钱包倒计时承诺固定交付时间。[挖矿如何保护付款](/blog/zh-hans/how-mining-secures-blocknet-payments/)解释确认深度的意义。

## 处理不足额、多付或无法匹配的付款

| 已核实的情况 | 下一步 |
|---|---|
| 1.25 BNT 订单只收到 1.00 BNT | 记录部分付款，请客户补足 0.25 BNT。 |
| 稍后又收到 0.25 BNT | 保存两个 ID，合计 1.25 BNT 且不重复计入，检查两笔入账的确认。 |
| 超过 1.25 BNT | 确认退款还是保留约定的余额，并记录决定。 |
| 金额正确但没有备注 | 分配给订单前，与客户核对完整 ID 和收款目标。 |
| 付款仍在等待 | 保持等待确认状态，稍后重新检查。 |

退款时，通过原有订单对话请客户确认收款地址。不要从公开交易推断退款地址：Blocknet 的公开输入不提供传统意义上的发送人地址。批准新的转账前，检查退款金额、目标和手续费，将新交易 ID 与原付款一起保存。

## 只分享所需的付款证据

公开浏览器可以帮助检查交易是否被收录，但不会公开你的地址收到的隐私金额。若对到账有争议，发送人可以按[付款证明指南](https://seineminer.com/zh-hans/blog/blocknet-payment-proof/)提供特定交易的证据。核实收款人匹配、金额和链上状态；仅证明密钥有效并不足够。

将订单、付款请求、入账 ID、核实金额、确认决定和退款记录一起私密保存。仅向客户分享相关收据或证明，不要将恢复词、钱包密码或整个钱包的私有查看密钥当作付款证据发送。

如果还在挖 BNT，即使用同一个钱包，也要把[矿池付款记录](/blog/zh-hans/track-your-miner-on-bntpool/)与客户订单分开，明确哪笔转账支付了哪张账单。
