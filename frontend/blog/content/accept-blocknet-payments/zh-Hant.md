接收 Blocknet 付款時，先向客戶說明準確的 BNT 金額，在自己的錢包中確認入帳，再將入帳記錄歸入訂單。本文使用 **1.25 BNT**、編號 **order-1042** 的虛構訂單，依據已發布的桌面錢包 v0.22.0，截圖均使用明確標示的示範資料。

## 如何接收 Blocknet 付款？

<Answer>
約定 BNT 金額及訂單編號，傳送指向你所控制地址的付款請求，等待已同步的錢包收到款項。核對金額和編號，檢查確認狀態，然後記錄交易 ID，按照與客戶約定的確認規則將訂單標記為已付款。
</Answer>

建立或開啟錢包可參閱[桌面錢包指南](https://seineminer.com/zh-hant/blog/blocknet-desktop-wallet/)。將還原備份與訂單記錄分開保存。接收客戶付款不需要執行挖礦程式或加入礦池。

## 確定金額並識別訂單

記錄訂單編號、BNT 金額、收款地址及購買內容。如果以其他貨幣報價，請在付款前約定 BNT 金額和報價有效時間。付款連結包含請求的金額，但不會更新匯率或強制執行到期時間。

範例請求 **1.25 BNT**，備註為 **order-1042**。訂單編號已經足夠；收貨地址等客戶資訊留在自己的私有訂單系統中。[加密備註](https://seineminer.com/zh-hant/blog/blocknet-encrypted-memos/)隨付款傳送，但任何收到共用連結的人都能閱讀寫在連結裡的備註。

在 **Receive → Payment Request** 填寫金額及備註，選擇 **Generate Payment Link**。分享前核對收款人與金額。[付款連結指南](https://seineminer.com/zh-hant/blog/blocknet-payment-links/)介紹連結格式及以名稱指定的收款人。對固定帳單，請同時保存完整收款地址。

## 在自己的錢包中核對入帳

請客戶填寫訂單編號並保留交易 ID。節點和錢包同步完成後，開啟 **History** 找到入帳，核對金額及備註。付款人可以修改這兩個欄位，因此請求本身無法證明實際傳送了什麼。

保存完整交易 ID 和入帳金額。不要因同一交易出現在 Dashboard 和 History，或客戶再次傳來同一 ID，就重複計算。應配對具體入帳，而非總餘額變化；總餘額可能也包含挖礦收入、其他客戶款項及自己的轉帳。

若找不到款項，與客戶核對完整目標地址及交易 ID，再檢查同步。傳送頁面的截圖可以提供線索，但實際入帳金額應由自己的收款錢包確認。

## 何時將訂單標記為已付款？

區分未確認的入帳、已包含在區塊中的交易及可以花費的資金。已發布的錢包會在一般付款所在區塊之後再等待十個區塊，才允許花費對應輸出。[轉帳時間指南](https://seineminer.com/zh-hant/blog/blocknet-transfer-time/)說明計數方式和不固定的等待時間。

在客戶付款前說明確認規則。簡單的手動流程可以等到對應入帳可花費後再交付。僅看到入帳金額不代表檢查已完成。區塊產生間隔會變化，不要依錢包倒數計時承諾固定交付時間。[挖礦如何保護付款](/blog/zh-hant/how-mining-secures-blocknet-payments/)解釋確認深度的意義。

## 處理不足額、多付或無法配對的付款

| 已核實的情況 | 下一步 |
|---|---|
| 1.25 BNT 訂單只收到 1.00 BNT | 記錄部分付款，請客戶補足 0.25 BNT。 |
| 稍後又收到 0.25 BNT | 保存兩個 ID，合計 1.25 BNT 且不重複計入，檢查兩筆入帳的確認。 |
| 超過 1.25 BNT | 確認退款還是保留約定餘額，並記錄決定。 |
| 金額正確但沒有備註 | 分配給訂單前，與客戶核對完整 ID 及收款目標。 |
| 付款仍在等待 | 保持等待確認狀態，稍後重新檢查。 |

退款時，透過原有訂單對話請客戶確認收款地址。不要從公開交易推斷退款地址：Blocknet 的公開輸入不提供傳統意義上的傳送人地址。核准新轉帳前，檢查退款金額、目標及手續費，將新交易 ID 與原付款一起保存。

## 只分享所需的付款證據

公開瀏覽器可以協助檢查交易是否被收錄，但不會公開你的地址收到的隱私金額。若對入帳有爭議，傳送人可按[付款證明指南](https://seineminer.com/zh-hant/blog/blocknet-payment-proof/)提供特定交易的證據。核實收款人配對、金額及鏈上狀態；僅證明金鑰有效並不足夠。

將訂單、付款請求、入帳 ID、核實金額、確認決定及退款記錄一起私密保存。僅向客戶分享相關收據或證明，不要將復原詞、錢包密碼或整個錢包的私有檢視金鑰當作付款證據傳送。

若也在挖 BNT，即使用同一錢包，也要將[礦池付款記錄](/blog/zh-hant/track-your-miner-on-bntpool/)與客戶訂單分開，明確哪筆轉帳支付了哪張帳單。
