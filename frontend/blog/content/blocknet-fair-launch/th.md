Blocknet เริ่มโดยไม่มีการจัดสรรเหรียญให้ใครล่วงหน้า หน้านี้แสดงสิ่งที่อยู่ในบล็อก genesis กฎฉันทามติที่ไม่อนุญาต premine กองทุนผู้พัฒนา หรือคลังสำรอง วิธีตรวจบน explorer และในซอร์สโค้ด รวมถึงวิธีเริ่มขุด BNT ด้วยตนเองบน bntpool.com

## Blocknet มี premine หรือไม่?

<Answer>
ไม่มี บล็อก genesis ของ Blocknet ที่สร้างเมื่อ 15 กุมภาพันธ์ 2026 ไม่มีธุรกรรม จึงไม่มีเหรียญก่อนเริ่มขุด ตั้งแต่บล็อก 1 ทุกบล็อกจ่ายรางวัลผ่านเอาต์พุต coinbase เดียวตามจำนวนที่กำหนดพอดี ทุก BNT ที่หมุนเวียนจึงมาจากผู้ที่ทำ proof of work เพื่อขุด
</Answer>

ไม่มีการจัดสรรให้ผู้ก่อตั้ง ผู้พัฒนา นักลงทุน หรือมูลนิธิ ทั้งใน genesis และบล็อกหลังจากนั้น อุปทานมาจากรางวัลบล็อกเท่านั้น กฎที่บังคับเรื่องนี้เป็นส่วนของฉันทามติ ทุกโหนดจึงตรวจทุกบล็อก

## บล็อก genesis ของ Blocknet มีอะไร?

Genesis ถูกกำหนดตายตัวใน daemon ทุกโหนดจึงเริ่มจากบล็อก 0 เดียวกัน ฟิลด์มีค่าคงที่ดังนี้:

| ฟิลด์ | ค่า |
|---|---|
| ความสูง | 0 |
| เวลา | 15 กุมภาพันธ์ 2026, 20:58:38 EST (16 กุมภาพันธ์ 01:58:38 UTC) |
| ข้อความ | "Wired 2026/02/15 - The Nothing That Has the Potential to Be Anything" |
| แฮชก่อนหน้า | SHA3-256 ของข้อความ: `a94a7f2b…d909df` |
| ความยาก | 4 ซึ่งเป็นค่าต่ำสุดของเครือข่าย |
| Nonce | 0 |
| ธุรกรรม | ไม่มี |
| Merkle root | ศูนย์ทั้งหมด |

ข้อความนี้เป็นพาดหัวข่าว Wired วันที่ 15 กุมภาพันธ์ 2026 และโค้ดอ้างบทความนั้นเป็นแหล่งที่มา เนื่องจากแฮชก่อนหน้ามาจากข้อความ พาดหัวจึงถูกตรึงไว้ในตัวตนของบล็อก 0 และทุกสิ่งที่ต่อจากมัน

คอมเมนต์เหนือฟังก์ชัน genesis ใน daemon ระบุชัดว่า genesis ไม่มีธุรกรรม ไม่มี coinbase และไม่มีเหรียญที่เผา บล็อกจริงแรกที่ความสูง 1 จะมี coinbase แรก กฎตรวจสอบยืนยันตามนั้น โหนดจะปฏิเสธบล็อก 0 หากไม่ได้มีธุรกรรมศูนย์รายการและ merkle root เป็นศูนย์ทั้งหมด แม้โหนดที่แก้ไขเองก็แอบเพิ่มเหรียญใน genesis ไม่ได้โดยไม่ถูกโหนดอื่นปฏิเสธ

## ฉันทามติป้องกันกองทุนผู้พัฒนาหรือคลังสำรองอย่างไร?

<Answer>
ทุกบล็อก Blocknet ต้องเริ่มด้วย coinbase หนึ่งธุรกรรมพอดี ไม่มีอินพุต ค่าธรรมเนียมเป็นศูนย์ และมีเอาต์พุตเดียวที่มูลค่าเท่ารางวัลของความสูงนั้น ไม่มีตำแหน่งสำหรับการจ่ายที่สอง จึงไม่สามารถมีเอาต์พุตกองทุนผู้พัฒนา รางวัลผู้ก่อตั้ง หรือคลังสำรองบนเชนได้
</Answer>

Daemon ใช้หลายการตรวจร่วมกัน:

- **หนึ่ง coinbase ต่อบล็อก** ธุรกรรมแรกต้องเป็น coinbase และธุรกรรมอื่นในบล็อกห้ามเป็น coinbase
- **หนึ่งเอาต์พุต ไม่มีอินพุต** Coinbase ที่มีศูนย์หรือสองเอาต์พุต หรือมีอินพุต ถือว่าไม่ถูกต้อง
- **รางวัลตรงตามจำนวน** Blocknet ซ่อนจำนวนเงินด้วย Pedersen commitments แต่ coinbase เป็นกรณีพิเศษ ค่าบังข้อมูลคำนวณจากข้อมูลสาธารณะ ได้แก่กุญแจสาธารณะของธุรกรรมและความสูงบล็อก ทุกโหนดจึงสร้าง commitment ของรางวัลตามตารางแล้วเทียบได้ หากเอาต์พุตผูกกับจำนวนอื่น บล็อกถูกปฏิเสธ
- **Memo ว่าง** Memo ของ coinbase ต้องว่าง รางวัลบล็อกจึงใส่ข้อมูลเพิ่มเติมไม่ได้เช่นกัน

ธุรกรรมปกติสร้างเหรียญไม่ได้ ทุกธุรกรรมต้องสมดุล: อินพุตเท่ากับเอาต์พุตบวกค่าธรรมเนียม โดยตรวจบน commitments โดยตรง แต่ละเอาต์พุตมี Bulletproofs range proof ว่าจำนวนอยู่ในช่วงที่ถูกต้องและไม่ติดลบ วิธีนี้ทำให้จำนวนเงินยังเป็นส่วนตัว แต่การออกเหรียญตรงตามตารางทุกประการ

## ตรวจสอบการเปิดตัวอย่างเป็นธรรมด้วยตนเองอย่างไร?

ไม่ต้องเชื่อคำพูดของใคร ทั้งเชนและโค้ดเปิดเผยต่อสาธารณะ

**บน explorer** เปิด[บล็อก 0 ใน Blocknet explorer](https://explorer.blocknetcrypto.com/block/0) จะเห็นธุรกรรม 0 รายการ merkle root เป็นศูนย์ 64 ตัว nonce เท่ากับ 0 และแฮชก่อนหน้าเริ่มด้วย `a94a7f2b` บรรทัดรางวัลแสดงจำนวนตามตารางของความสูงนั้น แต่เมื่อไม่มีธุรกรรมก็ไม่มีเอาต์พุตรับเงิน จากนั้นเปิด[บล็อก 1](https://explorer.blocknetcrypto.com/block/1) ธุรกรรมเดียวคือ coinbase ไม่มีอินพุตและมีเอาต์พุตเดียว ซึ่งเป็นเหรียญแรกบนเชน

ยืนยันได้ว่าแฮชก่อนหน้าคือแฮชของข้อความ genesis จริง ใช้ OpenSSL 1.1.1 ขึ้นไปแล้วรัน:

```sh
printf '%s' 'Wired 2026/02/15 - The Nothing That Has the Potential to Be Anything' | openssl dgst -sha3-256
```

ผลลัพธ์ลงท้ายด้วย `a94a7f2b8685ff3c7dc76de5ad0f13568629b1f0e0495440c58a3ed3d0d909df` ตรงกับค่าบล็อก 0 บน explorer

**ในโค้ด** Daemon เป็นโอเพนซอร์สที่ [github.com/blocknetprivacy/core](https://github.com/blocknetprivacy/core) ใน [`block.go`](https://github.com/blocknetprivacy/core/blob/master/block.go) ให้หาฟังก์ชันเหล่านี้:

```sh
git clone https://github.com/blocknetprivacy/core.git
cd core
grep -n "func GetGenesisBlock\|func validateGenesisBlock\|func validateCoinbaseConsensus" block.go
```

`GetGenesisBlock` สร้างบล็อก 0 ด้วยรายการธุรกรรมว่าง `validateGenesisBlock` ปฏิเสธบล็อก 0 ที่มีธุรกรรม และ `validateCoinbaseConsensus` บังคับเอาต์พุตเดียวเท่ารางวัล ใน `transaction.go` ฟังก์ชัน `validateCoinbase` และ `verifyCommitmentBalance` ตรวจรูปแบบ coinbase และความสมดุลของธุรกรรมปกติ

## การเปิดตัวอย่างเป็นธรรมสำคัญต่อนักขุดอย่างไร?

สำหรับนักขุด การเปิดตัวอย่างเป็นธรรมหมายความว่ารางวัลบล็อกอธิบายที่มาของเหรียญได้ทั้งหมด

- **เหรียญใหม่ทั้งหมดเป็นของนักขุด** เมื่อไม่มี premine หรือเอาต์พุตคลังสำรอง การออกเหรียญ 100% จ่ายให้ผู้พบบล็อก บล็อก 1 จ่าย 723.25093035 BNT ในเอาต์พุต coinbase เดียว และทุกบล็อกหลังจากนั้นจ่ายรางวัลเต็มแบบเดียวกัน
- **ทุกคนใช้กฎเดียวกัน** ตั้งแต่บล็อก 1 วิธีเดียวที่จะได้ BNT ใหม่คือทำ proof of work [ตารางรางวัล](/blog/th/blocknet-block-reward-schedule/) กำหนดในโค้ดและใช้เหมือนกันกับนักขุดคนแรกและผู้เริ่มวันนี้
- **Proof of work เหมาะกับคอมพิวเตอร์ทั่วไป** Blocknet ใช้ Argon2id กับหน่วยความจำ 2 GiB ต่อ hash ออกแบบให้ต้านทาน ASICs การขุดจึงเข้าถึงได้ด้วยเดสก์ท็อป แล็ปท็อป และเซิร์ฟเวอร์ที่มีอยู่แล้ว [บทอธิบาย Argon2id บน seineminer.com](https://seineminer.com/th/blog/argon2id-proof-of-work-explained/) อธิบายเหตุผล
- **ตรวจสอบการออกเหรียญได้ง่าย** ทุกเหรียญมาจากเอาต์พุต coinbase ที่ทุกโหนดตรวจแล้ว ยอดออกสะสม ณ ความสูงใดจึงคำนวณตรงจากตารางรางวัลได้

หากเพิ่งรู้จักเหรียญนี้ [Blocknet คืออะไร?](https://seineminer.com/th/blog/what-is-blocknet/) อธิบายความเป็นส่วนตัว การจ่ายด้วยชื่อ และกระเป๋าเงิน

## ขุด Blocknet ด้วยตนเองอย่างไร?

การร่วมในการเปิดตัวอย่างเป็นธรรมคือการขุด วิธีเริ่มที่เร็วคือใช้ seine บน bntpool.com:

1. **เตรียมที่อยู่** ติดตั้ง[กระเป๋าบรรทัดคำสั่ง](https://github.com/blocknetprivacy/blocknet/releases/latest)หรือ[กระเป๋าเดสก์ท็อป](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)ทางการของ Blocknet แล้วคัดลอกที่อยู่ หรือใช้ชื่อ Blocknet ID เช่น `@name`
2. **ดาวน์โหลด seine** รับไฟล์สำหรับ Windows, macOS หรือ Linux จาก [seineminer.com](https://seineminer.com/th/#download) แล้วแตกไฟล์ ไม่ต้องติดตั้ง
3. **เปิดและยอมรับค่าเริ่มต้น** เปิด seine วางที่อยู่หรือ `@name` แล้วกด Enter เพื่อใช้ `stratum+tcp://bntpool.com:3333` โปรแกรมเริ่มแฮชทันทีและปรับเธรดกับเคอร์เนลขณะทำงาน ใช้ CPU และการ์ด NVIDIA บน Windows และ Linux
4. **ติดตามเครื่องขุด** ค้นหาที่อยู่ใน[หน้าสถิติ](/stats)เพื่อดู hashrate, share และยอดคงเหลือ แล้วติดตามบล็อกที่พูลพบใน[หน้าบล็อก](/blocks)
