最初のシェアが受理されたら、My Statsを開いて作業がプールに届いているか確認しましょう。自分のマシンを見つけ、時間をかけてハッシュレートを比較し、推定報酬が確定して支払われるまでを追います。スクリプトと公開APIは最後に説明します。

まだ採掘を始めていない場合は、[seineのインストールガイド](https://seineminer.com/ja/blog/how-to-mine-blocknet/)に従えば数分で最初のシェアを送信できます。

## bntpool.comで自分のマイナーの統計を確認するには？

<Answer>
bntpool.com/statsでMy Statsを開き、Blocknetアドレスまたは@nameを貼り付けてLookupを押します。ハッシュレート、受理・拒否シェア、推定・確定・支払済み残高、ハッシュレートのグラフ、採掘機ごとの行、最近の支払いが表示されます。タブを開いている間は自動更新されます。
</Answer>

[My Stats](/stats)に移動し、seineに指定したものと同じアドレスまたは[Blocknet ID短縮名](https://seineminer.com/ja/blog/blocknet-id-pay-by-name/)を入力します。`@name`や`$name`のような名前はblocknet.idを通じて解決され、検索欄にその名前が指す完全なアドレスが表示されます。ページはブラウザー内で前回の検索を記憶するため、次回はすぐに自分の数値を確認できます。

1. **Shares Accepted**と**Recent Shares**を確認します。受理済みシェアがあれば、報酬残高がすべてゼロでも作業はプールに届いています。
2. **Workers**で自分のマシンを探します。Seineに表示される名前と一致し、最後のシェアの時刻が更新されているか確認します。
3. **Blocks Found**がゼロでも正常です。これは自分のマシンが解いたブロック数であり、プール報酬の配分を受けられるかどうかを示す値ではありません。

## My Statsには何が表示されますか？

ページはカードと表のグループに分かれており、それぞれがマイナーについての疑問に答えます。

### 採掘とシェア

**Mining**カードには、現在の**Hashrate**、自分の採掘機がプールのために解いた**Blocks Found**、開始日である**Mining Since**が表示されます。その下には**Shares Accepted**、**Shares Rejected**、**Reject Rate**、**Avg Difficulty**があります。正常な採掘機では受理シェアが継続的に増え、拒否率はゼロに近い値になります。

**Hashrate History**は、1h、24h、7d、30dの期間でハッシュレートをグラフ表示します。マシンが一晩中稼働していたかを確認するには、長めの期間が適しています。

### 採掘機ごとに1行

複数のマシンを使う場合はそれぞれに名前を付けると、プールがハッシュレート、受理・拒否シェア、最後のシェアの時刻を別々に表示します。Seineは初回起動時に`seine-`と4桁の数字を組み合わせた名前を選びます。コマンドラインで自分の名前を指定することもできます。

```sh
./seine --pool-worker rig-01
```

**Workers**表には各マシンのマイナーバージョンも表示されます。古いバージョンや不明なバージョンがあると、統計の上に通知が表示され、[seineのリリースページ](https://github.com/zpalmtree/seine/releases)へ進めます。

## プールとseineでハッシュレートが違うのはなぜですか？

Seineはマシンが計算する全ハッシュを数えます。プールが見られるのは提出されたシェアだけなので、直近1時間に受理したシェアの難易度の合計からハッシュレートを推定します。各シェアの発見はランダムであり、bntpool.comは5分ごとに約10シェアを目標とする接続別の難易度を設定するため、短い期間ではばらつきが出ます。

次の2点を意識すると数値を比較しやすくなります。

- 平均同士を比べます。My Statsの24hグラフと、seineの同じ期間の平均を比較してください。
- 新しい採掘機には時間を与えます。起動直後は採掘していた数分間で平均を計算するため、最初の値は少数のシェアに基づきます。1時間後には完全な1時間のウィンドウが適用されます。

ハッシュレートが落ち着く前でも、Recent Shares表を見ればシェアが届いていることをすぐに確認できます。

## 最初の支払いはいつ届きますか？

最初のシェアから支払いまでの時間は決まっていません。まず、あなたのシェアが支払いウィンドウ内にある間にプールがブロックを発見する必要があります。そのブロックには60承認が必要で、**ブロック発見後**から平均で約5時間かかりますが、実際の時間は変動します。確定残高が現在の最低支払額0.1 BNTに達すると、自動支払い処理の対象になります。最新の設定は[Get Started](/start)で確認してください。

**Recent Payouts**で支払い状況とトランザクションリンクを確認できます。待機中の支払いはまだネットワークへ送信されていません。送信済みの支払いがウォレットに表示されない場合は、[支払いのトラブル対処ガイド](/blog/ja/pool-payout-missing-from-wallet/)をご覧ください。

### 残高

- **Estimated Rewards：** プールが発見した、まだ成熟中のブロックに対する自分の取り分。
- **Confirmed Rewards：** 成熟済みで、次の支払いを待っている残高。
- **Paid Balance：** すでに自分のアドレスへ送られた総額。

処理中の報酬があると、**Estimated From Recent Blocks**という表に、各ブロックの高さ、推定付与額、残り承認数、発見時刻が表示されます。各高さから[Blocknetエクスプローラー](https://explorer.blocknetcrypto.com)の該当ブロックに移動できるため、自分で照合できます。[PPLNS支払いの仕組み](/blog/ja/how-pplns-payouts-work/)では、各ブロックの報酬の分配方法と残高が支払われる時期を説明しています。

### 支払いと最近のシェア

**Recent Payouts**には、自分のアドレスへの各支払いについて、金額、エクスプローラーの取引リンク、queued・unconfirmed・confirmedの状態が表示されます。**Recent Shares**には、最新20件のシェアのジョブ、採掘機、難易度、状態が表示されます。起動したばかりのマシンがプールに届いているかを最も早く確認できます。

## seine がマイニング中なのに My Stats のハッシュレートがゼロなのはなぜですか？

まず報酬受取アドレス、プールへの接続、受理されたシェアを確認します。ローカルのハッシュレートはマシンがハッシュを計算していることを示します。プールの推定値には、検索したアドレスで受理されたシェアが必要です。

1. **アドレスを照合します。** seine が使用している受取アドレスまたは登録済みの `@name` と同じものを検索してください。短縮名のアドレスを変更した場合は、seine を再起動して名前を再解決し、解決されたアドレスを My Stats で確認します。
2. **プールを照合します。** seine が `stratum+tcp://bntpool.com:3333` を使用しているか確認してください。別のプールやソロモードで動くマシンからは、ここにシェアは追加されません。[プール設定ガイド](/blog/ja/mine-blocknet-on-bntpool/)で接続手順を確認できます。
3. **Recent Shares を確認します。** シェアが受理されるのを待ち、ページの更新を待ってください。シェアの到着間隔は一定ではなく、ローカルのハッシュレートが動いていても、プールの推定値がすぐに表示されるとは限りません。受理されたシェアが届いているなら、時間をかけて平均値を比較します。
4. **接続メッセージを読みます。** まだシェアが受理されていない場合は次の表を使ってください。現在の障害は [Status](/status) で確認できます。

| seine のメッセージ | 次に確認すること |
|---|---|
| `failed to connect to pool at` | ホスト名とポート、接続状態、ポート 3333 への送信 TCP 接続が許可されているかを確認します。 |
| `login rejected:` | 後に続く理由を読み、受取アドレスまたは短縮名を確認し、最新の seine を使用してください。 |
| `stale job` | シェアが古いジョブを参照しています。新しいジョブと受理されたシェアを確認し、続く場合は接続とマイナーのバージョンを確認します。 |
| `submit interrupted during reconnect` | seine が再接続中です。接続が戻った後、ログインが受理され、新しいシェアが受理されるか確認します。 |

**Estimated Rewards** がゼロなのは別の問題です。プールのブロック報酬が計上される前にも、シェアは受理されます。その順序は [PPLNS ガイド](/blog/ja/how-pplns-payouts-work/)で説明しています。

## プール全体を確認できる公開ページは？

これらのページは検索不要で、プールの動作を公開しています。[ダッシュボード](/)には、接続中の採掘者数、プールとネットワークのハッシュレート、発見ブロック数、平均の運といった主要な数値がまとまっています。

### ブロック

[Blocks](/blocks)には、bntpool.comが発見した全ブロックが新しい順に並びます。高さ（エクスプローラーへのリンク）、報酬、仕事量の比率、ラウンド時間、状態、発見時刻を確認できます。Confirmed、Pending、Orphanedで絞り込み、各ブロックの状態を確認できます。

### 支払い

[Payouts](/payouts)には、各支払いバッチの総額、受取人数、取引リンク、状態が表示されます。バッチはブロードキャスト直後にunconfirmedとなり、最初のブロック承認後まもなくconfirmedに変わります。自分への支払いをプール側とエクスプローラーの両方から追跡できます。

### 運

[Luck](/luck)は各ラウンドの仕事量の比率を示します。これはラウンド中にプールが受理したシェアの仕事量をブロック難易度で割った値です。100%なら期待どおりの仕事量でブロックが見つかり、低い値なら早く見つかったことを意味します。個々のラウンドは上下に大きく変動するため、注目するのはダッシュボードの**Average Luck**です。**Pool Luck History**表の**View All**からこのページへ移動できます。

### 状態

[Status](/status)はプール自身の稼働状況ページです。プール、公開HTTP、API、Stratum、データベース、デーモンの稼働状態、現在のジョブテンプレートの鮮度、チェーン高、直近10分・6時間・24時間・7日間の稼働率、障害履歴が表示されます。稼働率は、プールサーバー内の監視とCloudflare上の外部プローブの2か所で計測されます。

## seine自身のダッシュボードは？

プールは、付与された報酬を表示します。マシンそのものをリアルタイムで見るには、seineのターミナルダッシュボードでハッシュレートとシェアを確認できます。Seineは、REST、サーバー送信イベントストリーム、`/metrics`のPrometheusメトリクスを備えたローカル制御APIも公開でき、既定では`127.0.0.1:9977`にバインドされます。[制御APIガイド](https://github.com/zpalmtree/seine/blob/master/docs/API.md)でフラグとエンドポイントを説明しています。各マシンにはseineのメトリクス、残高と支払いにはプールAPIというように、両方を使う採掘者も多くいます。

## bntpool.comのAPIを使うには？

<Answer>
bntpool.comのAPIはHTTPSで公開されたJSONで、キーは不要です。https://bntpool.com/api/miner/の後ろに自分のアドレスを付けると、ハッシュレート、採掘機、シェア、支払いを取得できます。残高には/balanceを追加し、プールとネットワークのハッシュレートには/api/statsを使います。金額は最小単位なので、100,000,000で割るとBNTになります。
</Answer>

上記の各ページはこれらのエンドポイントから読み込むので、サイト上で見える情報は自分でも取得できます。

| エンドポイント | 返される情報 |
|---|---|
| `/api/stats` | 接続中の採掘者数、プールのハッシュレート、発見ブロック数、ネットワークのハッシュレート、現在の高さ |
| `/api/stats/history?range=24h` | 時系列のプールハッシュレート（`1h`、`24h`、`7d`、`30d`） |
| `/api/stats/insights` | 現在のラウンド、平均仕事量比率、最近のラウンド |
| `/api/info` | プール設定：Stratumポート、支払い方式とウィンドウ、最低支払額 |
| `/api/blocks?status=confirmed` | 発見ブロック。状態で絞り込み可能 |
| `/api/payouts/recent` | 取引ハッシュ付きの支払いバッチ |
| `/api/luck` | 各ラウンドの仕事量比率と所要時間 |
| `/api/status` | サービスの状態、期間別稼働率、障害 |
| `/api/miner/{address}` | 自分のハッシュレート、累計、採掘機、最新シェア、支払い |
| `/api/miner/{address}/balance` | 推定・確定・支払済み残高 |
| `/api/miner/{address}/hashrate?range=24h` | 自分のハッシュレート履歴 |

一覧エンドポイントは`limit`（既定25、最大200）と`offset`を受け取り、`items`と`total`を返します。採掘者のエンドポイントには完全なアドレスが必要なので、My Statsで@nameを検索した後、検索欄から完全なアドレスをコピーしてください。

ターミナルから自分のマイナー情報を取得するには、次を実行します。

```sh
curl -s https://bntpool.com/api/miner/YOUR_ADDRESS
```

`jq`を使うと、ハッシュレートと受理シェア数や、BNT単位の支払済み総額など、個別の値を取り出せます。

```sh
curl -s https://bntpool.com/api/miner/YOUR_ADDRESS | jq '{hashrate, total_accepted, total_rejected}'
curl -s https://bntpool.com/api/miner/YOUR_ADDRESS/balance | jq '.balance.paid / 100000000'
```
