本指南說明如何在 bntpool.com 上單獨挖 Blocknet：在 seine 中為地址加一個前綴，礦池就會把你的礦機找到的每個區塊的全部獎勵支付給你。你不需要安裝或同步節點。你將學會如何設定、單獨挖礦的區塊如何支付，以及在礦池哪裡查看它們。

## 什麼是 bntpool.com 上的單獨挖礦？

<Answer>
在 bntpool.com 上單獨挖礦時，你只獲得自己礦機找到的區塊，每個區塊的全部區塊獎勵都支付到你的地址。礦池仍然負責執行節點、建立區塊範本並提交你的區塊，所以你用與礦池挖礦相同的設定就能獲得單獨挖礦的收益。在地址前加上 solo: 即可開啟。
</Answer>

在一般的礦池挖礦中，bntpool.com 會把每個區塊分給份額落在六小時 PPLNS 區間內的礦工，因此你能分到礦池找到的每個區塊的一部分。單獨挖礦的礦機則保留自己找到的區塊的全部獎勵，不分享其他人找到的區塊。兩者使用同一個伺服器、同一個地址與同樣的支付方式，只有登入方式不同。

透過礦池單獨挖礦，你無需維護節點就能獲得單獨挖礦的收益：

- **無需執行節點。** 礦池的節點跟進區塊鏈、提供最新範本並提交你解出的區塊。
- **自動支付。** 你的區塊像 bntpool.com 的其他支付一樣，付到你的地址或 Blocknet ID 名稱。
- **即時統計。** 你的礦機、算力與區塊會顯示在礦池的[統計頁面](/stats)上。
- **一個前綴即可切換。** 去掉 `solo:` 並重新啟動 seine，就會回到分享收益。

另一種單獨挖礦方式是 seine 的 daemon 模式，對接你自己已同步的 Blocknet 節點挖礦。[Blocknet 礦池挖礦與單獨挖礦（solo）怎麼選](/blog/zh-hant/pool-vs-solo-mining-blocknet/)比較了這三種方式，並說明你的算力多久能找到一個區塊。

## 如何用 seine 開始單獨挖礦？

<Answer>
安裝 seine v0.3.1 或更新版本，然後在 Blocknet 地址前加上 solo: 啟動它，例如在 macOS 或 Linux 上執行 ./seine --address solo:YOUR_ADDRESS。seine 會連線到它的預設礦池 bntpool.com，儀表板會把你的帳戶標為 Solo。首次執行時 seine 詢問收款地址，你也可以直接輸入 solo: 加地址。
</Answer>

1. **更新 seine。** 單獨挖礦登入需要 seine v0.3.1 或更新版本。[下載 seine](https://seineminer.com/zh-hant/#download)，或讓自動更新為你安裝。
2. **帶前綴啟動 seine。** 在 macOS 或 Linux 上：

   ```sh
   ./seine --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   在 Windows 上，於 PowerShell 中執行：

   ```powershell
   .\seine.exe --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   seine 預設在 bntpool.com 挖礦。礦池的 [Get Started 頁面](/start)提供了寫明礦池地址的同一條命令。
3. **查看儀表板。** 餘額面板會把你的帳戶標為 **Solo**，日誌會顯示礦池的確認：這個地址找到的區塊將支付給你。

凡是 seine 接受地址的地方都可以使用這個前綴：首次執行的提示、儲存的設定、本機控制 API 以及礦場代理下的礦機。seine 會把前綴與地址一起儲存，所以之後的執行會繼續單獨挖礦。

## 可以用 Blocknet ID 名稱單獨挖礦嗎？

可以。Blocknet ID 名稱的用法與完整地址相同。寫成 `solo:@name` 或 `solo:$name`，並加上引號，讓 shell 原樣傳遞：

```sh
./seine --address 'solo:@yourname'
```

礦池會在 blocknet.id 解析該名稱，並把你的單獨挖礦區塊支付到它對應的地址。要為礦機命名，可以在完整地址後加一個點再寫名稱，例如 `solo:YOUR_ADDRESS.rig1`，或者在任何地址或名稱之外傳入 `--pool-worker rig1`。前綴不區分大小寫，所以 `SOLO:` 也可以。

## 單獨挖礦的區塊如何支付？

當你的礦機找到區塊時，礦池會把它記錄為單獨挖礦區塊。區塊達到 60 個區塊深度後（約五小時），礦池會把它的全部區塊獎勵扣除礦池手續費後記入你的餘額。截至 2026年11月4日，手續費為 0%。之後，你的餘額會透過礦池的正常支付發送到你的地址。

支付規則與礦池挖礦相同。每個區塊都要等待 60 個確認，這樣短暫的鏈重組就無法撤銷已經支付的獎勵，[區塊確認與未成熟挖礦獎勵](/blog/zh-hant/block-confirmations-mining-rewards/)說明了原因。礦池的 `/api/info` 介面在 2026年11月4日回報的最低支付額為 1 BNT，而一個 Blocknet 區塊獎勵遠高於此，所以已確認的單獨挖礦區塊會依礦池的正常支付週期支付。[支付頁面](/payouts)列出了礦池發出的每一筆付款。

如果你挖礦到帶支付備註（memo）的交易所入金地址，單獨挖礦同樣適用。備註及其本身的最低支付額對單獨挖礦區塊的作用與對分享收益完全相同。

你的礦機的工作仍然計入礦池的算力、本輪努力值與運氣，單獨挖礦區塊也會像其他區塊一樣結束礦池的當前輪次。單獨挖礦的份額不會進入 PPLNS 區間，所以其他礦工不會從你的區塊中獲得收益，你也不會從他們的區塊中獲得收益。

## 單獨挖礦的礦機多久能找到一個區塊？

Blocknet 的目標是每五分鐘出一個塊，即每天 288 個區塊。單獨挖礦的礦機平均每天能找到 288 × (你的算力 ÷ 全網算力) 個。在 [bntpool.com 首頁](/)查看全網算力，在 seine 儀表板上查看你自己的算力，再用一天除以結果，就得到你平均多久找到一個區塊。

單獨挖礦的收益以整個區塊入帳，因此適合算力能頻繁找到區塊的礦工：大型礦場、伺服器叢集以及占全網算力比例較大的礦工。較小的礦機透過分享的 PPLNS 收益，平均能獲得同樣多的收益，並從礦池找到的每個區塊中穩定地分到一部分。[Blocknet 礦池挖礦與單獨挖礦（solo）怎麼選](/blog/zh-hant/pool-vs-solo-mining-blocknet/)用三種算力做了計算範例。

## 在哪裡查看你的單獨挖礦礦機與區塊？

在[統計頁面](/stats)上查詢你的地址，帶不帶 `solo:` 前綴都可以。頁面會這樣標出你的單獨挖礦工作：

- **Workers** 列出每台礦機，在算力統計區間內發送過單獨挖礦份額的礦機，其 Type 欄顯示 **Solo**。
- **Estimated rewards** 會標出仍在等待確認的單獨挖礦區塊。
- **Blocks** 與 **Luck** 在每個區塊的狀態前有一欄 Type，顯示 Pool 或 Solo。[區塊頁面](/blocks)由新到舊列出礦池找到的每一個區塊。

[在 bntpool.com 上查看你的礦機](/blog/zh-hant/track-your-miner-on-bntpool/)說明了統計頁面的其餘部分。

## 可以同時使用單獨挖礦與礦池挖礦的礦機嗎？

可以。每台礦機在連線時選擇模式，所以一個地址可以同時執行單獨挖礦的礦機與礦池挖礦的礦機。礦場可以讓最大的伺服器單獨挖礦，桌上型電腦繼續分享收益，全部支付到同一個餘額。礦池會把這兩類工作分開：在單獨挖礦連線上找到的份額，只計入該地址的單獨挖礦區塊。

要把礦機切換回來，在命令或儲存的設定中去掉地址裡的 `solo:`，然後重新啟動 seine。礦機在單獨挖礦模式下已經發送的份額仍算作單獨挖礦，新的份額會立即進入 PPLNS 區間。
