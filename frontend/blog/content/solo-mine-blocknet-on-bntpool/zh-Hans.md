本指南介绍如何在 bntpool.com 上单独挖 Blocknet：在 seine 中给地址加一个前缀，矿池就会把你的矿机找到的每个区块的全部奖励支付给你。你不需要安装或同步节点。你将学会如何设置、单独挖矿的区块如何支付，以及在矿池哪里查看它们。

## 什么是 bntpool.com 上的单独挖矿？

<Answer>
在 bntpool.com 上单独挖矿时，你只获得自己矿机找到的区块，每个区块的全部区块奖励都支付到你的地址。矿池仍然负责运行节点、构建区块模板并提交你的区块，所以你用和矿池挖矿相同的设置就能获得单独挖矿的收益。在地址前加上 solo: 即可开启。
</Answer>

在普通的矿池挖矿中，bntpool.com 会把每个区块分给份额落在六小时 PPLNS 窗口内的矿工，因此你能分到矿池找到的每个区块的一部分。单独挖矿的矿机则保留自己找到的区块的全部奖励，不分享其他人找到的区块。两者使用同一个服务器、同一个地址和同样的支付方式，只有登录方式不同。

通过矿池单独挖矿，你无需维护节点就能获得单独挖矿的收益：

- **无需运行节点。** 矿池的节点跟进区块链、提供最新模板并提交你解出的区块。
- **自动支付。** 你的区块像 bntpool.com 的其他支付一样，付到你的地址或 Blocknet ID 名称。
- **实时统计。** 你的矿机、算力和区块会显示在矿池的[统计页面](/stats)上。
- **一个前缀即可切换。** 去掉 `solo:` 并重启 seine，就会回到分享收益。

另一种单独挖矿方式是 seine 的 daemon 模式，对接你自己已同步的 Blocknet 节点挖矿。[Blocknet 矿池挖矿与单独挖矿（solo）怎么选](/blog/zh-hans/pool-vs-solo-mining-blocknet/)比较了这三种方式，并说明你的算力多久能找到一个区块。

## 如何用 seine 开始单独挖矿？

<Answer>
安装 seine v0.3.1 或更新版本，然后在 Blocknet 地址前加上 solo: 启动它，例如在 macOS 或 Linux 上运行 ./seine --address solo:YOUR_ADDRESS。seine 会连接它的默认矿池 bntpool.com，仪表盘会把你的账户标为 Solo。首次运行时 seine 询问收款地址，你也可以直接输入 solo: 加地址。
</Answer>

1. **更新 seine。** 单独挖矿登录需要 seine v0.3.1 或更新版本。[下载 seine](https://seineminer.com/zh-hans/#download)，或让自动更新为你安装。
2. **带前缀启动 seine。** 在 macOS 或 Linux 上：

   ```sh
   ./seine --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   在 Windows 上，于 PowerShell 中运行：

   ```powershell
   .\seine.exe --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   seine 默认在 bntpool.com 挖矿。矿池的 [Get Started 页面](/start)给出了写明矿池地址的同一条命令。
3. **查看仪表盘。** 余额面板会把你的账户标为 **Solo**，日志会显示矿池的确认：这个地址找到的区块将支付给你。

凡是 seine 接受地址的地方都可以使用这个前缀：首次运行的提示、保存的配置、本地控制 API 以及矿场代理下的矿机。seine 会把前缀和地址一起保存，所以之后的运行会继续单独挖矿。

## 可以用 Blocknet ID 名称单独挖矿吗？

可以。Blocknet ID 名称的用法和完整地址相同。写成 `solo:@name` 或 `solo:$name`，并加上引号，让 shell 原样传递：

```sh
./seine --address 'solo:@yourname'
```

矿池会在 blocknet.id 解析该名称，并把你的单独挖矿区块支付到它对应的地址。要给矿机命名，可以在完整地址后加一个点再写名称，例如 `solo:YOUR_ADDRESS.rig1`，或者在任何地址或名称之外传入 `--pool-worker rig1`。前缀不区分大小写，所以 `SOLO:` 也可以。

## 单独挖矿的区块如何支付？

当你的矿机找到区块时，矿池会把它记录为单独挖矿区块。区块达到 60 个区块深度后（约五小时），矿池会把它的全部区块奖励扣除矿池手续费后记入你的余额。截至 2026年11月4日，手续费为 0%。之后，你的余额会通过矿池的正常支付发送到你的地址。

支付规则与矿池挖矿相同。每个区块都要等待 60 个确认，这样短暂的链重组就无法撤销已经支付的奖励，[区块确认与未成熟挖矿奖励](/blog/zh-hans/block-confirmations-mining-rewards/)解释了原因。矿池的 `/api/info` 接口在 2026年11月4日报告的最低支付额为 1 BNT，而一个 Blocknet 区块奖励远高于此，所以已确认的单独挖矿区块会按矿池的正常支付周期支付。[支付页面](/payouts)列出了矿池发出的每一笔付款。

如果你挖矿到带支付备注（memo）的交易所充值地址，单独挖矿同样适用。备注及其自身的最低支付额对单独挖矿区块的作用与对分享收益完全相同。

你的矿机的工作仍然计入矿池的算力、本轮努力值和运气，单独挖矿区块也会像其他区块一样结束矿池的当前轮次。单独挖矿的份额不会进入 PPLNS 窗口，所以其他矿工不会从你的区块中获得收益，你也不会从他们的区块中获得收益。

## 单独挖矿的矿机多久能找到一个区块？

Blocknet 的目标是每五分钟出一个块，即每天 288 个区块。单独挖矿的矿机平均每天能找到 288 × (你的算力 ÷ 全网算力) 个。在 [bntpool.com 首页](/)查看全网算力，在 seine 仪表盘上查看你自己的算力，再用一天除以结果，就得到你平均多久找到一个区块。

单独挖矿的收益以整个区块到账，因此适合算力能频繁找到区块的矿工：大型矿场、服务器集群以及占全网算力比例较大的矿工。较小的矿机通过分享的 PPLNS 收益，平均能获得同样多的收益，并从矿池找到的每个区块中稳定地分到一部分。[Blocknet 矿池挖矿与单独挖矿（solo）怎么选](/blog/zh-hans/pool-vs-solo-mining-blocknet/)用三种算力做了计算示例。

## 在哪里查看你的单独挖矿矿机和区块？

在[统计页面](/stats)上查询你的地址，带不带 `solo:` 前缀都可以。页面会这样标出你的单独挖矿工作：

- **Workers** 列出每台矿机，在算力统计窗口内发送过单独挖矿份额的矿机，其 Type 列显示 **Solo**。
- **Estimated rewards** 会标出仍在等待确认的单独挖矿区块。
- **Blocks** 和 **Luck** 在每个区块的状态前有一列 Type，显示 Pool 或 Solo。[区块页面](/blocks)按从新到旧列出矿池找到的每一个区块。

[在 bntpool.com 上查看你的矿机](/blog/zh-hans/track-your-miner-on-bntpool/)介绍了统计页面的其余部分。

## 可以同时使用单独挖矿和矿池挖矿的矿机吗？

可以。每台矿机在连接时选择模式，所以一个地址可以同时运行单独挖矿的矿机和矿池挖矿的矿机。矿场可以让最大的服务器单独挖矿，台式机继续分享收益，全部支付到同一个余额。矿池会把这两类工作分开：在单独挖矿连接上找到的份额，只计入该地址的单独挖矿区块。

要把矿机切换回来，在命令或保存的配置中去掉地址里的 `solo:`，然后重启 seine。矿机在单独挖矿模式下已经发送的份额仍算作单独挖矿，新的份额会立即进入 PPLNS 窗口。
