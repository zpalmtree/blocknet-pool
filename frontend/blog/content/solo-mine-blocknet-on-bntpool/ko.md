이 가이드는 bntpool.com에서 Blocknet을 솔로 채굴하는 방법을 설명합니다. Seine에서 주소에 접두사 하나를 붙이면 장비가 찾은 각 블록의 전체 보상을 풀이 지급합니다. 노드를 설치하거나 동기화할 필요가 없습니다. 설정 방법, 솔로 블록의 지급 방식, 풀에서 확인하는 위치를 알아봅니다.

## bntpool.com의 솔로 채굴이란 무엇인가요?

<Answer>
bntpool.com의 솔로 채굴은 자신의 장비가 찾은 블록에 대해서만 지급하며, 각 블록의 전체 블록 보상이 자신의 주소로 지급됩니다. 노드 운영, 블록 템플릿 생성, 블록 제출은 여전히 풀이 맡으므로 풀 채굴과 같은 설정으로 솔로 보상을 받습니다. 주소 앞에 solo:를 붙이면 켜집니다.
</Answer>

일반 풀 채굴에서 bntpool.com은 각 블록을 6시간 PPLNS 구간에 셰어가 있는 채굴자들과 나누므로, 풀이 찾는 각 블록의 일부를 받습니다. 솔로 장비는 대신 자신이 찾은 블록의 전체 보상을 갖고, 다른 사람이 찾은 블록에서는 받지 않습니다. 두 방식 모두 같은 서버, 같은 주소, 같은 지급을 사용하며 로그인만 달라집니다.

풀을 통한 솔로 채굴은 노드를 관리하는 수고 없이 솔로 보상을 줍니다.

- **노드가 필요 없습니다.** 풀의 노드가 체인을 따라가고, 새 템플릿을 제공하며, 해결한 블록을 제출합니다.
- **자동 지급.** 자신의 블록은 다른 bntpool.com 지급과 똑같이 주소나 Blocknet ID 이름으로 지급됩니다.
- **실시간 통계.** 장비, 해시레이트, 블록이 풀의 [통계 페이지](/stats)에 표시됩니다.
- **접두사 하나로 전환.** `solo:`를 빼고 seine을 재시작하면 공유 보상으로 돌아갑니다.

다른 솔로 채굴 방법은 seine의 daemon 모드로, 동기화된 자신의 Blocknet 노드에서 채굴합니다. [Blocknet 풀 채굴과 솔로 채굴 비교](/blog/ko/pool-vs-solo-mining-blocknet/)에서 세 가지 방법을 비교하고 자신의 해시레이트로 얼마나 자주 블록을 찾는지 보여 줍니다.

## Seine으로 솔로 채굴을 시작하려면 어떻게 하나요?

<Answer>
Seine v0.3.1 이상을 설치한 뒤 Blocknet 주소 앞에 solo:를 붙여 실행하세요. macOS나 Linux에서는 ./seine --address solo:YOUR_ADDRESS입니다. Seine은 기본 풀인 bntpool.com에 연결하고 대시보드에 계정이 Solo로 표시됩니다. 첫 실행에서 지급 주소를 물을 때 solo:와 주소를 입력해도 됩니다.
</Answer>

1. **Seine을 업데이트합니다.** 솔로 로그인에는 seine v0.3.1 이상이 필요합니다. [seine을 내려받거나](https://seineminer.com/ko/#download) 자동 업데이트로 설치하세요.
2. **접두사를 붙여 seine을 실행합니다.** macOS나 Linux에서는 다음과 같습니다.

   ```sh
   ./seine --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   Windows에서는 PowerShell에서 실행합니다.

   ```powershell
   .\seine.exe --address solo:YOUR_BLOCKNET_ADDRESS
   ```

   Seine은 기본적으로 bntpool.com에서 채굴합니다. 풀의 [Get Started 페이지](/start)에는 풀 주소까지 적힌 같은 명령이 있습니다.
3. **대시보드를 확인합니다.** 잔액 패널에 계정이 **Solo**로 표시되고, 로그에는 이 주소가 찾은 블록에 대해 지급한다는 풀의 확인이 나타납니다.

접두사는 seine이 주소를 받는 모든 곳에서 작동합니다. 첫 실행 입력, 저장된 설정, 로컬 제어 API, 팜 프록시 장비입니다. Seine은 주소와 함께 저장하므로 이후 실행에서도 계속 솔로로 채굴합니다.

## Blocknet ID 이름으로 솔로 채굴할 수 있나요?

네. Blocknet ID 이름은 전체 주소와 같은 방식으로 작동합니다. `solo:@name` 또는 `solo:$name`으로 쓰고, 셸이 그대로 전달하도록 따옴표로 감싸세요.

```sh
./seine --address 'solo:@yourname'
```

풀은 blocknet.id에서 이름을 변환하고 그 뒤의 주소로 솔로 블록을 지급합니다. 장비에 이름을 붙이려면 `solo:YOUR_ADDRESS.rig1`처럼 전체 주소 뒤에 점을 찍고 추가하거나, 어떤 주소나 이름과 함께든 `--pool-worker rig1`을 전달하세요. 접두사는 대소문자를 구분하지 않으므로 `SOLO:`도 작동합니다.

## 솔로 블록은 어떻게 지급되나요?

장비가 블록을 찾으면 풀은 이를 솔로 블록으로 기록합니다. 블록이 60블록 깊이, 약 5시간에 도달하면 풀은 전체 블록 보상에서 풀 수수료를 뺀 금액을 잔액에 적립합니다. 2026년 11월 4일 기준 수수료는 0%입니다. 이후 잔액은 풀의 일반 지급으로 주소에 송금됩니다.

지급은 풀 채굴과 같은 규칙을 따릅니다. 각 블록은 60컨펌을 기다리므로 짧은 체인 재구성으로 이미 지급된 보상이 취소되지 않습니다. 이유는 [블록 컨펌과 채굴 보상](/blog/ko/block-confirmations-mining-rewards/)에서 설명합니다. 풀의 `/api/info` 엔드포인트는 2026년 11월 4일에 최소 지급액을 1 BNT로 보고했고, Blocknet 블록 보상 하나는 이를 훨씬 넘으므로 컨펌된 솔로 블록은 풀의 일반 지급 일정에 따라 지급됩니다. [지급 페이지](/payouts)에는 풀이 보내는 모든 지급이 나열됩니다.

지급 메모와 함께 거래소 입금 주소로 채굴해도 솔로는 같은 방식으로 작동합니다. 메모와 그 자체의 최소 지급액은 공유 보상과 마찬가지로 솔로 블록에도 적용됩니다.

장비의 작업은 여전히 풀의 해시레이트, 라운드 투입 작업량, 운에 포함되며, 솔로 블록도 다른 블록처럼 풀의 라운드를 끝냅니다. 솔로 셰어는 PPLNS 구간에 들어가지 않으므로 다른 채굴자는 자신의 블록에서 받지 않고, 자신도 다른 채굴자의 블록에서 받지 않습니다.

## 솔로 장비는 얼마나 자주 블록을 찾나요?

Blocknet은 5분마다 한 블록, 하루 288블록을 목표로 합니다. 솔로 장비는 하루 평균 288 × (자신의 해시레이트 ÷ 네트워크 해시레이트)개의 블록을 찾습니다. 네트워크 해시레이트는 [bntpool.com 첫 페이지](/)에서, 자신의 해시레이트는 seine 대시보드에서 확인한 뒤 하루를 그 결과로 나누면 블록 사이의 평균 시간이 됩니다.

솔로 보상은 블록 단위로 들어오므로 블록을 자주 찾는 해시레이트를 가진 채굴자에게 적합합니다. 대형 팜, 서버 집단, 네트워크의 큰 비중을 차지하는 채굴자입니다. 작은 장비는 공유 PPLNS 보상으로도 평균적으로 같은 금액을 받으며, 풀이 찾는 모든 블록에서 꾸준히 나누어 지급받습니다. [Blocknet 풀 채굴과 솔로 채굴 비교](/blog/ko/pool-vs-solo-mining-blocknet/)에서 세 가지 해시레이트로 계산 예시를 보여 줍니다.

## 솔로 장비와 블록은 어디에서 확인하나요?

[통계 페이지](/stats)에서 주소를 검색하세요. `solo:` 접두사는 붙여도 되고 빼도 됩니다. 페이지는 솔로 작업을 다음과 같이 표시합니다.

- **Workers**에는 각 장비가 나열되며, 해시레이트 구간 안에 솔로 셰어를 보낸 장비는 Type 열에 **Solo**로 표시됩니다.
- **Estimated rewards**는 컨펌을 기다리는 솔로 블록을 표시합니다.
- **Blocks**와 **Luck**에는 각 블록의 상태 앞에 Pool 또는 Solo를 나타내는 Type 열이 있습니다. [블록 페이지](/blocks)에는 풀이 찾은 모든 블록이 최신순으로 나열됩니다.

통계 페이지의 나머지는 [bntpool.com에서 채굴기 상태 확인하기](/blog/ko/track-your-miner-on-bntpool/)에서 설명합니다.

## 솔로 장비와 풀 장비를 함께 운영할 수 있나요?

네. 각 장비는 연결할 때 방식을 정하므로 한 주소로 솔로 장비와 풀 장비를 동시에 운영할 수 있습니다. 팜은 가장 큰 서버로 솔로 채굴을 하고 데스크톱은 공유 보상으로 두면서 모두 하나의 잔액으로 받을 수 있습니다. 풀은 두 종류의 작업을 분리합니다. 솔로 연결에서 찾은 셰어는 해당 주소의 솔로 블록에만 반영됩니다.

장비를 되돌리려면 명령이나 저장된 설정의 주소에서 `solo:`를 빼고 seine을 재시작하세요. 솔로 모드에서 이미 보낸 셰어는 솔로로 남고, 새 셰어는 바로 PPLNS 구간에 들어갑니다.
