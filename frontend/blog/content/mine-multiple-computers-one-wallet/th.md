เพิ่มคอมพิวเตอร์เครื่องที่สองไปยัง bntpool.com โดยยังใช้กระเป๋ารับเดียว ตั้งชื่อแต่ละการติดตั้ง ตรวจแยกกัน แล้วติดตามที่อยู่รวม คู่มือนี้ครอบคลุมการเพิ่มเครื่องและชื่อซ้ำ สำหรับตัวขุดเครื่องแรก ให้ทำ[การตั้งค่าพูล](/blog/th/mine-blocknet-on-bntpool/) ให้เสร็จก่อน

## หลายเครื่องขุดเข้ากระเป๋าเดียวกันได้หรือไม่?

<Answer>
ได้ เรียกใช้ seine บนแต่ละเครื่องด้วยที่อยู่รับเดียวกันและชื่อเครื่องต่างกัน bntpool.com บันทึกงานกับรางวัลตามที่อยู่ ส่วนชื่อช่วยแยกกิจกรรมในสถิติ ตรวจแชร์ที่ยอมรับจากแต่ละเครื่องก่อนพึ่งพาหน้ารวมของที่อยู่
</Answer>

*คอมพิวเตอร์แต่ละเครื่องส่งงานผ่านพูลไปยังที่อยู่รับเดียว โดยแต่ละเครื่องเก็บชื่อที่แตกต่างกัน*

## เลือกที่อยู่รับและรูปแบบชื่อ

ใช้ที่อยู่รับของกระเป๋าหรือ Blocknet ID ที่ชี้ไปยังที่อยู่นั้น ตรวจที่อยู่ที่แก้จากชื่อบนทุกตัวขุด ชื่อช่วยให้กรอกสะดวก แต่บัญชีอิงที่อยู่ผลลัพธ์ หากเปลี่ยนปลายทาง ID การขุดที่ทำงานอยู่อาจใช้ที่อยู่เดิมจนเริ่มใหม่ รางวัลที่ได้แล้วคงอยู่กับที่อยู่เดิม

[คู่มือกระเป๋าสำหรับขุด](https://seineminer.com/th/blog/blocknet-wallet-for-mining/) อธิบายการหาที่อยู่ เครื่องขุดต้องใช้เพียงปลายทางสาธารณะนี้ เก็บวลีกู้คืนและกุญแจส่วนตัวไว้กับกระเป๋า เลือกชื่อสั้น เช่น `desktop-01` และ `server-02` พูลตัดช่องว่างหัวท้ายและเก็บไม่เกิน 64 อักขระ วางส่วนที่แยกเครื่องไว้ต้นชื่อยาว

## เพิ่มตัวขุดที่สองด้วยชื่อของมัน

ติดตั้ง seine รุ่นที่เหมาะบนเครื่องที่สองและเรียกจากโฟลเดอร์ที่แตกไฟล์ ตัวอย่าง PowerShell แรกระบุชื่อผู้รับ พูล และเครื่องอย่างชัดเจน แทน `@yourname` ด้วย ID หรือที่อยู่เต็มของคุณก่อนเรียกใช้ คงเครื่องหมายคำพูด และเพิ่มตัวเลือก backend หรือปรับแต่งที่ทดสอบแล้วของเครื่องนั้น

```powershell
.\seine.exe --address "@yourname" --pool-url stratum+tcp://bntpool.com:3333 --pool-worker desktop-01
```

บน Linux หรือ macOS ใช้โปรแกรมในคำสั่งด้านล่างกับชื่อเครื่องอีกชื่อ ระบบปฏิบัติการต่างกันได้ แต่ที่อยู่รับควรตรงกัน แต่ละตัวอย่างเริ่มขุดจริง เรียกตัวอย่างที่เหมาะบนเครื่องนั้นและรอการเริ่มกับปรับแต่งตามปกติ ไม่ต้องเรียกทั้งสองตัวอย่างบนเครื่องเดียว

```sh
./seine --address "@yourname" --pool-url stratum+tcp://bntpool.com:3333 --pool-worker server-02
```

## การตั้งค่าใดใช้ร่วมกัน?

ใช้ที่อยู่รับและปลายทางพูลร่วมกัน แต่เก็บโฟลเดอร์ข้อมูลท้องถิ่นกับชื่อแยกต่อการติดตั้ง seine บันทึกการเชื่อมต่อใน `seine.config.json` ภายในโฟลเดอร์ข้อมูล ค่าเริ่มต้น `./seine-data` ขึ้นกับโฟลเดอร์ที่เรียกใช้ การเริ่มจากอีกโฟลเดอร์อาจพบการตั้งค่าอีกชุด ตำแหน่งคงที่ช่วยดูแลได้ง่าย

ถ้าคัดลอกการตั้งค่าจากเครื่องแรก ให้ระบุชื่อใหม่ในคำสั่งเริ่มเครื่องที่สองและตรวจตอนเริ่ม คงชื่อที่ระบุชัดนั้นในคำสั่งครั้งต่อไปด้วย เพราะการแทนค่าผ่านคำสั่งไม่เขียนทับชื่อที่บันทึกไว้ ปรับตัวเลือกฮาร์ดแวร์ให้เหมาะและให้แต่ละเครื่องปรับแต่งเอง อาร์กิวเมนต์ที่อยู่กำหนดการจ่าย ส่วนชื่อกำหนดป้าย กรอกแยกตามตัวอย่าง

## ตรวจว่าทั้งสองเครื่องส่งงานอย่างไร?

เปิด My Stats บน bntpool.com แล้วค้นหาที่อยู่ร่วม มองหาสองชื่อและแชร์ล่าสุดของแต่ละเครื่อง ตรวจการส่งที่ยอมรับในตัวขุดแต่ละตัวด้วย ตรวจทีละเครื่องเพื่อเชื่อมโปรเซสกับแถวของพูล จะหาข้อผิดพลาดง่ายกว่าดูเพียงแฮชเรตรวม

พูลประมาณแฮชเรตจากแชร์ที่ส่ง เครื่องใหม่อาจต้องใช้เวลาและงานที่ยอมรับก่อนค่าจะมีความหมาย อัตราในเครื่องกับค่าพูลเป็นการวัดและช่วงเวลาต่างกัน ยืนยันกิจกรรมจากแชร์ล่าสุดและจำนวนที่ยอมรับก่อน แล้วค่อยเทียบช่วงยาว [คู่มือสถิติ](/blog/th/track-your-miner-on-bntpool/) อธิบายการ์ดและแถวโดยไม่อนุมานจำนวนอุปกรณ์จากจำนวนการเชื่อมต่อ

## ถ้าเครื่องหายไปหรือชื่อซ้ำต้องทำอย่างไร?

ชื่อเดียวใต้ที่อยู่เดียวจะรวมแชร์ที่บันทึก เปลี่ยนชื่อหนึ่งตัวด้วยตัวเลือกชื่อแล้วเริ่มตัวขุดนั้นใหม่ การส่งใหม่ใช้ป้ายใหม่ ส่วนประวัติเก็บป้ายเดิม แถวเก่าอาจยังแสดงขณะประวัติอยู่ในช่วงรายงาน การเปลี่ยนชื่อไม่ย้ายยอดที่ที่อยู่ได้รับแล้ว

สำหรับเครื่องที่ไม่ปรากฏ ให้เทียบที่อยู่จริงที่แก้จากชื่อ ปลายทางพูล และชื่อกับหน้าที่เปิด ตรวจการเชื่อมต่อกับแชร์ที่ยอมรับ CPU และ GPU ในโปรเซส seine เดียวไม่ต้องมีชื่อแยกในขั้นตอนนี้ หากแชร์ถูกปฏิเสธหรือล้าสมัย ให้ตาม[คู่มือสถานะแชร์](/blog/th/accepted-rejected-stale-shares/) แทนการเปลี่ยนที่อยู่กระเป๋าซ้ำๆ

## รางวัลรวมและการจ่ายทำงานอย่างไร?

งานที่ถูกต้องจากทุกเครื่องมีส่วนของที่อยู่เดียวกันในหน้าต่าง PPLNS ชื่อช่วยติดตามส่วนร่วม ไม่สร้างยอดแยก เครื่องที่เพิ่มส่งมอบงานมีประโยชน์ที่ส่งจริง ไม่ใช่รางวัลคงที่ต่ออุปกรณ์หรือต่อชื่อ ฮาร์ดแวร์และเวลาทำงานต่างกันอาจมีส่วนร่วมต่างกัน การเพิ่มชื่ออย่างเดียวไม่เพิ่มงาน

[คู่มือ PPLNS](/blog/th/how-pplns-payouts-work/) อธิบายการแบ่งเมื่อพูลพบบล็อก กฎยืนยันและจ่ายยังใช้กับยอดรวมของที่อยู่ ไม่ต้องรวมกระเป๋าหรือย้ายยอดระหว่างชื่อ ก่อนปล่อยให้ทำงาน ตรวจปลายทาง ชื่อที่ต่าง และแชร์ที่ยอมรับในทุกเครื่อง ใช้รายการสั้นนี้อีกเมื่อเพิ่มเครื่องถัดไป
