你可以在保留一个收款钱包的同时，为 bntpool.com 添加第二台电脑。为每套安装命名，分别核验，再监控共用地址。本指南介绍添加机器和解决重名的方法。第一台矿工请先完成[矿池设置指南](/blog/zh-hans/mine-blocknet-on-bntpool/)。

## 多台电脑可以向同一个钱包挖矿吗？

<Answer>
可以。在每台电脑上使用相同收款地址和不同机器名称运行 seine。bntpool.com 按地址记录工作与奖励，名称则区分统计中的活动。在依赖地址总览之前，先确认每台机器都有已接受的份额。
</Answer>

*不同电脑通过矿池向一个收款地址提交工作，各自保留独立名称。*

## 选择收款地址和命名方式

使用钱包收款地址，或解析到该地址的 Blocknet ID。让矿工持续运行前，检查每台机器解析出的地址。名称便于输入，但记账依据是最终地址。更改 ID 指向后，现有挖矿进程可能在重启前继续使用原解析结果；已获得的奖励仍属于原地址。

[挖矿钱包指南](https://seineminer.com/zh-hans/blog/blocknet-wallet-for-mining/)说明如何获取地址。机器只需这个公开收款目标，恢复短语和私钥留在钱包端。选择 `desktop-01` 和 `server-02` 等简短名称。矿池会去掉首尾空白，最多保留 64 个字符，因此应将区分部分放在长名称开头。

## 用独立名称添加第二台矿工

在第二台电脑安装适合的 seine 版本，并从解压文件夹运行。第一个 PowerShell 示例明确指定收款名称、矿池和机器名。运行前，把 `@yourname` 替换为自己的 ID 或完整收款地址，保留引号，并按需加入这台机器已验证的后端或调优选项。

```powershell
.\seine.exe --address "@yourname" --pool-url stratum+tcp://bntpool.com:3333 --pool-worker desktop-01
```

Linux 或 macOS 使用下方命令的程序及另一个机器名称。操作系统可以不同，收款地址应一致。每个示例都会开始实际挖矿。只在对应电脑运行适合的示例，等待正常启动和调优完成，不需要在同一台机器上运行两个示例。

```sh
./seine --address "@yourname" --pool-url stratum+tcp://bntpool.com:3333 --pool-worker server-02
```

## 哪些设置由电脑共享？

共享收款地址与矿池连接端点，但每套安装保留独立的本地数据文件夹和名称。seine 将连接保存在数据目录的 `seine.config.json` 中；默认 `./seine-data` 取决于启动文件夹。从另一目录运行可能找到其他配置，固定启动位置更便于维护。

如果复制第一台电脑的配置，在第二台的启动命令中设置不同名称，并在启动信息中确认。之后的命令也保留显式名称：命令行覆盖不会改写已保存的名称。硬件选项要适合对应电脑，让它在本机调优。地址参数决定收款目标，名称参数决定显示标签，按示例分别输入。

## 如何确认两台电脑都在贡献工作？

在 bntpool.com 打开 My Stats，查询共同收款地址。检查两个名称以及各自最近的份额，也在每台矿工上确认已接受的提交。一次核验一台电脑，可将本地进程与矿池行对应起来，比只看总哈希率更容易发现错误。

矿池按提交的份额估算哈希率，新机器可能需要时间和已接受的工作才能显示有参考价值的数值。本地速率与矿池估值的测量及时间范围不同。先用最近份额和接受计数确认活动，再比较更长时间。[统计指南](/blog/zh-hans/track-your-miner-on-bntpool/)解释卡片和行，无需根据连接总数推断设备数。

## 机器缺失或名称相同时怎么办？

同一地址下使用相同名称，会将记录的份额合并。通过名称选项重命名其中一个矿工，再重启它。新提交使用新标签，旧记录保留原标签。历史份额仍在报告范围内时，旧行可能继续显示。改名不会移动地址已经获得的余额。

对于未显示的机器，将实际解析地址、端点和名称与所查看的页面比较，再检查连接及已接受份额。同一 seine 进程中的 CPU 与 GPU 在此配置下不需要分开命名。遇到拒绝或过时份额，按[份额状态指南](/blog/zh-hans/accepted-rejected-stale-shares/)排查，不要反复更换钱包地址。

## 合并奖励与付款如何运作？

电脑的有效工作共同计入同一地址在 PPLNS 窗口中的参与量。名称帮助追踪贡献，不创建独立余额。添加机器增加的是其实际提交的有效工作，而非每台设备或每个名称固定的奖励。硬件和运行时长不同，贡献也可能不同；仅增加名称不会增加工作。

[PPLNS 指南](/blog/zh-hans/how-pplns-payouts-work/)解释矿池找到区块时的分配方式。确认和付款规则仍适用于地址的合并余额。不必合并钱包，也无需在机器名称间转移余额。让设备持续运行前，逐台确认收款目标、独立名称和已接受份额，添加下一台时复用这份清单。
