更改未来挖矿工作的收款目标，同时清楚保留此前奖励的记录。本指南适用于已经连接 bntpool.com 的 seine。首次连接请看[矿池设置指南](/blog/zh-hans/mine-blocknet-on-bntpool/)，创建新收款钱包请看[钱包指南](https://seineminer.com/zh-hans/blog/blocknet-wallet-for-mining/)。

## 怎样更改挖矿钱包地址？

<Answer>
停止一台矿工，在保存配置或日常启动命令中更新收款地址，再重启。核对解析出的完整地址和已接受份额，然后在 bntpool.com 查询该地址。对其他矿机重复操作。此前份额和奖励仍关联它们记录时使用的地址。
</Answer>

*新的挖矿工作流向第二个钱包，而旧奖励记录仍连接第一个钱包。*

## 切换前记录两个收款目标

从准备使用的钱包直接复制新收款地址。矿工只需要公开地址或注册的 Blocknet ID，不需要助记词或私钥。也保留原来的完整地址，因为更改设置后，它仍是查询旧矿池活动的依据。

打开旧地址的我的统计，记录待定奖励、已确认余额、近期付款和当前贡献工作的矿机名称。这是切换时的对照记录，不应期待新地址页面包含旧历史。在跟踪剩余奖励和付款期间，保留原钱包的访问能力。

## 先更新一台矿工并检查启动命令

停止一台矿工，检查平常如何启动。已有配置时，明确指定的 `--address` 优先于保存地址，但不会改写它。PowerShell 示例选择本次运行的目标。把 `@yourname` 换成自己的新 ID 或完整地址，并保留已验证的矿池、数据目录和硬件参数。

```powershell
.\seine.exe --address "@yourname"
```

Linux 或 macOS 从通常的启动目录使用下面的语法。两个示例都会开始实际挖矿，只选择适合自己系统的一个。其他连接设置来自已有安装。保留同一矿机名称，以便其份额出现在新地址下时能够辨认。

```sh
./seine --address "@yourname"
```

## 让下次正常启动也使用新地址

停止矿工后，编辑 `seine.config.json` 中的 `address`，保留其他字段及合法 JSON。确认数据目录：默认 `./seine-data` 相对于工作目录，`--data-dir` 可选择其他位置。编辑日常启动方式实际读取的文件。

更新或删除快捷方式、脚本、计划任务或服务里的旧 `--address`。一次手动命令成功不会更新其他启动入口。通过通常方式重启并再次验证。[seine 配置指南](https://seineminer.com/zh-hans/blog/configure-seine-miner/)解释保存值与覆盖参数的优先级，以及工作目录变化为何会读到其他配置。

## 使用 Blocknet ID 时有什么不同？

在 seine v0.2.37 中，`@name` 在启动时解析并验证。得到的完整地址在本次运行中保持固定，包括矿池重连。如果修改名称映射，请重启每台矿工并核对目标。仅让现有进程重连不会重复启动时的名称解析。

即便可读名称不变，也把新旧完整地址记下来。矿池按解析后的地址记账，因此修改映射不会重定向已有份额或余额。名称解析失败时，检查映射，或明确使用从钱包核实的完整收款地址。

## 在新地址下验证每台电脑

检查矿工目标和被接受的提交，再在我的统计中查询新的完整地址。对应矿机名称与近期份额。新算力估计需要提交工作和时间，所以先验证份额确实到达。[统计指南](/blog/zh-hans/track-your-miner-on-bntpool/)解释各项计数和矿机未出现时的检查方法。

第一台确认后，再逐一修改其余矿工。每台使用不同名称，更便于核对。还要检查各机的日常重启入口，避免旧启动方式日后恢复旧目标。[多电脑指南](/blog/zh-hans/mine-multiple-computers-one-wallet/)说明如何在一个收款地址下组织矿机。

## 旧地址的奖励会怎样？

已有奖励记账和付款仍归旧地址。此前符合条件的份额仍可参与相应 PPLNS 窗口，待定区块奖励继续遵循确认规则。算力立即变成零不代表全部结算已经结束。[PPLNS 指南](/blog/zh-hans/how-pplns-payouts-work/)与[确认指南](/blog/zh-hans/block-confirmations-mining-rewards/)区分已记录工作、成熟中的奖励和付款。

变更目标不会合并余额，也不会绕过最低付款额。检查矿池当前付款规则，并跟踪两个地址页面，直到理解剩余金额。重命名矿机也不会转移奖励。最后确认所有计划迁移的矿工都向新地址提交新工作，同时保留旧钱包及其历史。
