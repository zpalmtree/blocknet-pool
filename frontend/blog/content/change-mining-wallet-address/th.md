เปลี่ยนปลายทางสำหรับงานในอนาคตโดยยังเก็บประวัติรางวัลเดิมอย่างชัดเจน คู่มือนี้ใช้ seine ที่เชื่อมกับ bntpool.com อยู่แล้ว การเชื่อมครั้งแรกดู[คู่มือพูล](/blog/th/mine-blocknet-on-bntpool/) ส่วนกระเป๋ารับใหม่ดู[คู่มือกระเป๋า](https://seineminer.com/th/blog/blocknet-wallet-for-mining/)

## เปลี่ยนที่อยู่ขุดอย่างไร?

<Answer>
หยุดเครื่องหนึ่ง อัปเดตที่อยู่ในไฟล์หรือคำสั่งปกติ แล้วเริ่มใหม่ ตรวจที่อยู่เต็มที่แปลงได้และแชร์ที่ยอมรับ จากนั้นค้นหาที่อยู่บน bntpool.com ทำซ้ำกับเครื่องอื่น แชร์และรางวัลก่อนหน้ายังผูกกับที่อยู่ที่ใช้ตอนบันทึก
</Answer>

*งานใหม่ไปยังกระเป๋าที่สอง ส่วนบันทึกรางวัลเดิมยังเชื่อมกับกระเป๋าแรก*

## บันทึกปลายทางทั้งสองก่อนเปลี่ยน

คัดลอกที่อยู่ใหม่จากกระเป๋าที่ต้องการใช้โดยตรง เครื่องขุดต้องการเพียงที่อยู่สาธารณะหรือ Blocknet ID ที่ลงทะเบียน ไม่ต้องใช้วลีกู้คืนหรือกุญแจส่วนตัว เก็บที่อยู่เต็มเดิมไว้ด้วย เพราะยังใช้ค้นหากิจกรรมพูลก่อนหน้า

เปิดสถิติของฉันสำหรับที่อยู่เก่า บันทึกรางวัลรอ ยอดยืนยัน การจ่ายล่าสุด และชื่อเครื่องที่ใช้งาน เป็นข้อมูลอ้างอิงในการเปลี่ยน หน้าใหม่ไม่มีประวัติเก่า เก็บการเข้าถึงกระเป๋าเดิมขณะติดตามรางวัลและการจ่ายที่เหลือ

## อัปเดตหนึ่งเครื่องและตรวจคำสั่งเริ่ม

หยุดเครื่องและตรวจวิธีเริ่มปกติ เมื่อมีการตั้งค่าแล้ว `--address` มีลำดับสูงกว่าโดยไม่เปลี่ยนที่อยู่ที่บันทึก ตัวอย่าง PowerShell เลือกปลายทางครั้งนี้ แทน `@yourname` ด้วย ID ใหม่หรือที่อยู่เต็ม และเก็บอาร์กิวเมนต์พูล ข้อมูล และฮาร์ดแวร์ที่ทดสอบไว้

```powershell
.\seine.exe --address "@yourname"
```

บน Linux หรือ macOS ใช้รูปแบบด้านล่างจากโฟลเดอร์ปกติ ทั้งสองตัวอย่างเริ่มขุดจริง ให้เลือกตามระบบของคุณ การติดตั้งเดิมให้ค่าการเชื่อมต่ออื่น เก็บชื่อเครื่องเดิมเพื่อจำแชร์ของเครื่องนั้นเมื่อปรากฏใต้ที่อยู่ใหม่

```sh
./seine --address "@yourname"
```

## ให้การเริ่มปกติครั้งต่อไปใช้ที่อยู่ใหม่

ขณะหยุดเครื่อง แก้ `address` ใน `seine.config.json` เก็บฟิลด์อื่นและ JSON ที่ถูกต้อง `./seine-data` อ้างอิงโฟลเดอร์ทำงาน และ `--data-dir` อาจเลือกตำแหน่งอื่น แก้ไฟล์ที่วิธีเริ่มตามปกติใช้จริง

อัปเดตหรือลบ `--address` เก่าจากทางลัด สคริปต์ งานตามเวลา หรือบริการ คำสั่งมือที่สำเร็จไม่เปลี่ยนวิธีเริ่มอื่น เริ่มตามปกติแล้วตรวจอีกครั้ง [คู่มือตั้งค่า](https://seineminer.com/th/blog/configure-seine-miner/) อธิบายลำดับและเหตุที่เปลี่ยนโฟลเดอร์ทำงานแล้วอ่านไฟล์อื่น

## ใช้ Blocknet ID แล้วต่างอย่างไร?

ใน seine v0.2.37 จะตรวจและแปลง `@name` เป็นที่อยู่ตอนเริ่ม ที่อยู่เต็มคงที่ตลอดการทำงาน รวมการเชื่อมต่อพูลใหม่ หากเปลี่ยนการผูกชื่อ ให้เริ่มทุกเครื่องใหม่และตรวจปลายทาง การเชื่อมต่อใหม่ของโปรเซสเดิมไม่ทำการแปลงชื่อเริ่มต้นซ้ำ

จดที่อยู่เต็มเก่าและใหม่แม้ชื่ออ่านง่ายยังเหมือนเดิม การบัญชีใช้ที่อยู่ที่แปลงแล้ว การเปลี่ยนการผูกไม่ส่งต่อแชร์หรือยอดเก่า หากแปลงชื่อไม่ได้ ให้ตรวจการผูกหรือเลือกใช้ที่อยู่เต็มที่ตรวจจากกระเป๋าแล้วโดยตรง

## ตรวจทุกคอมพิวเตอร์ใต้ที่อยู่ใหม่

ตรวจปลายทางและงานที่ยอมรับ แล้วค้นหาที่อยู่ใหม่เต็มในสถิติของฉัน เทียบชื่อเครื่องกับแชร์ล่าสุด การประมาณแฮชเรตใหม่ต้องใช้งานและเวลา จึงตรวจว่างานมาถึงก่อน [คู่มือสถิติ](/blog/th/track-your-miner-on-bntpool/) อธิบายตัวนับและเครื่องที่ยังไม่ปรากฏ

เมื่อยืนยันเครื่องแรกแล้วทำกับที่เหลือ ชื่อเฉพาะช่วยตรวจง่ายขึ้น ทดสอบการเริ่มปกติทุกเครื่องด้วย เพื่อไม่ให้วิธีเริ่มเก่ากลับมาใช้ปลายทางเดิมภายหลัง [คู่มือหลายคอมพิวเตอร์](/blog/th/mine-multiple-computers-one-wallet/) อธิบายการจัดเครื่องใต้ที่อยู่รับเดียว

## รางวัลที่อยู่เก่าจะเป็นอย่างไร?

เครดิตและการจ่ายที่มีอยู่ยังเป็นของที่อยู่เก่า แชร์ก่อนหน้าที่มีสิทธิ์อาจยังมีส่วนในช่วง PPLNS ที่เกี่ยวข้อง รางวัลบล็อกที่รอยังเป็นไปตามกฎการยืนยัน แฮชเรตศูนย์ไม่ได้หมายความว่าการบัญชีเสร็จทั้งหมด [คู่มือ PPLNS](/blog/th/how-pplns-payouts-work/) และ[การยืนยัน](/blog/th/block-confirmations-mining-rewards/) แยกงาน รางวัลที่กำลังครบกำหนด และการจ่าย

การเปลี่ยนปลายทางไม่รวมยอดและไม่ข้ามขั้นต่ำการจ่าย ตรวจเงื่อนไขปัจจุบันและติดตามสองหน้าจนเข้าใจยอดที่เหลือ การเปลี่ยนชื่อเครื่องก็ไม่ย้ายรางวัล สุดท้ายยืนยันว่าทุกเครื่องที่ต้องการส่งงานใหม่ไปที่อยู่ใหม่ และเก็บกระเป๋าเก่ากับประวัติไว้
