變更未來挖礦工作的收款目標，同時清楚保留先前獎勵的記錄。本指南適用於已連接 bntpool.com 的 seine。首次連線請看[礦池設定指南](/blog/zh-hant/mine-blocknet-on-bntpool/)，建立新收款錢包請看[錢包指南](https://seineminer.com/zh-hant/blog/blocknet-wallet-for-mining/)。

## 怎樣變更挖礦錢包位址？

<Answer>
停止一台礦工，在儲存設定或日常啟動指令中更新收款位址，再重新啟動。核對解析出的完整位址與已接受份額，然後在 bntpool.com 查詢該位址。對其他礦機重複操作。先前份額與獎勵仍關聯記錄時使用的位址。
</Answer>

*新的挖礦工作流向第二個錢包，舊獎勵記錄仍連接第一個錢包。*

## 切換前記錄兩個收款目標

從準備使用的錢包直接複製新收款位址。礦工只需要公開位址或註冊的 Blocknet ID，不需要助記詞或私鑰。也保留原本的完整位址，因為變更設定後，它仍是查詢舊礦池活動的依據。

開啟舊位址的我的統計，記錄待定獎勵、已確認餘額、近期付款及目前貢獻工作的礦機名稱。這是切換時的對照記錄，不應期待新位址頁面包含舊歷史。追蹤剩餘獎勵與付款期間，保留原錢包的存取能力。

## 先更新一台礦工並檢查啟動指令

停止一台礦工，檢查平常如何啟動。已有設定時，明確指定的 `--address` 優先於儲存位址，但不會改寫它。PowerShell 範例選擇本次執行的目標。將 `@yourname` 換成自己的新 ID 或完整位址，並保留已驗證的礦池、資料目錄與硬體參數。

```powershell
.\seine.exe --address "@yourname"
```

Linux 或 macOS 從通常的啟動目錄使用下方語法。兩個範例都會開始實際挖礦，只選擇適合自己系統的一個。其他連線設定來自已有安裝。保留相同礦機名稱，以便其份額出現在新位址下時可以辨認。

```sh
./seine --address "@yourname"
```

## 讓下次正常啟動也使用新位址

停止礦工後，編輯 `seine.config.json` 中的 `address`，保留其他欄位及合法 JSON。確認資料目錄：預設 `./seine-data` 相對於工作目錄，`--data-dir` 可選擇其他位置。編輯日常啟動方式實際讀取的檔案。

更新或移除捷徑、指令碼、排程工作或服務裡的舊 `--address`。一次手動指令成功不會更新其他啟動入口。透過通常方式重新啟動並再次驗證。[seine 設定指南](https://seineminer.com/zh-hant/blog/configure-seine-miner/)說明儲存值與覆寫參數的優先順序，以及工作目錄變更為何會讀到其他設定。

## 使用 Blocknet ID 時有何不同？

在 seine v0.2.37 中，`@name` 在啟動時解析並驗證。取得的完整位址在本次執行中保持固定，包括礦池重新連線。若修改名稱對應，請重新啟動每台礦工並核對目標。僅讓現有程序重新連線不會重複啟動時的名稱解析。

即使可讀名稱不變，也將新舊完整位址記下來。礦池依解析後的位址記帳，因此修改對應不會重新導向已有份額或餘額。名稱解析失敗時，檢查對應，或明確使用從錢包核實的完整收款位址。

## 在新位址下驗證每台電腦

檢查礦工目標與被接受的提交，再於我的統計查詢新的完整位址。對應礦機名稱與近期份額。新算力估計需要提交工作和時間，因此先驗證份額確實到達。[統計指南](/blog/zh-hant/track-your-miner-on-bntpool/)說明各項計數與礦機未出現時的檢查方式。

第一台確認後，再逐一修改其餘礦工。各台使用不同名稱，更便於核對。也要檢查每台的日常重新啟動入口，避免舊啟動方式日後恢復舊目標。[多電腦指南](/blog/zh-hant/mine-multiple-computers-one-wallet/)說明如何在一個收款位址下組織礦機。

## 舊位址的獎勵會如何？

已有獎勵入帳與付款仍歸舊位址。先前符合條件的份額仍可參與相應 PPLNS 時窗，待定區塊獎勵繼續遵循確認規則。算力立即變成零不代表全部結算已結束。[PPLNS 指南](/blog/zh-hant/how-pplns-payouts-work/)與[確認指南](/blog/zh-hant/block-confirmations-mining-rewards/)區分已記錄工作、成熟中的獎勵和付款。

變更目標不會合併餘額，也不會繞過最低付款額。檢查礦池目前付款規則，並追蹤兩個位址頁面，直到理解剩餘金額。重新命名礦機也不會轉移獎勵。最後確認所有預計轉移的礦工都向新位址提交新工作，同時保留舊錢包及其歷史。
