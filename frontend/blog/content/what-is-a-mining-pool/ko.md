이 가이드는 마이닝 풀이 무엇인지, 대부분의 채굴자가 풀에 참여하는 이유와 각 채굴자의 수익을 계산하는 방식을 설명합니다. 일반적인 보상 방식인 PPLNS, PPS, 솔로 채굴과 풀에 연결하기 전에 확인할 사항을 알아봅니다. Blocknet 마이닝 풀인 bntpool.com을 전반적인 예시로 사용합니다.

## 마이닝 풀은 무엇인가요?

<Answer>
마이닝 풀은 여러 채굴자의 [해시레이트](/blog/ko/what-is-hashrate/)를 모아 함께 블록을 찾도록 하는 서버입니다. 풀은 각 채굴자에게 같은 블록에 대한 작업을 보내고, 제출된 작업량을 집계하며, 작업량에 비례해 블록 보상을 나눕니다. 채굴자는 드물게 블록 전체를 받는 대신 적은 금액을 자주 받습니다.
</Answer>

작업 증명 코인에서는 채굴자들이 서로 다른 논스로 블록 헤더를 해시하여 결과가 네트워크 목표값보다 낮아질 때까지 다음 블록을 찾기 위해 경쟁합니다. 각 해시는 동일한 작은 성공 확률을 가진 독립적인 시도이며, 성공한 해시를 찾은 사람이 블록 보상을 받습니다.

풀은 이 경쟁을 공동 작업으로 바꿉니다. bntpool.com에 연결된 모든 채굴자는 풀이 만든 블록을 작업하며, 누군가 성공한 해시를 찾으면 그 블록을 찾는 데 작업을 기여한 채굴자들 사이에 보상이 분배됩니다.

## 채굴자는 왜 마이닝 풀에 참여하나요?

<Answer>
채굴자는 꾸준히 보상을 받기 위해 풀에 참여합니다. 일반적인 개인 채굴자의 해시레이트는 네트워크의 극히 일부이므로, 혼자서는 불규칙한 간격으로 며칠씩 블록을 기다릴 수 있습니다. 풀은 합산 해시레이트로 블록을 자주 찾고 각 채굴자가 매번 일부를 받으므로, 해시레이트에 비례하는 수익을 정기적으로 얻습니다.
</Answer>

Blocknet에서는 계산을 쉽게 확인할 수 있습니다. 네트워크는 5분마다 한 블록, 하루 288블록을 목표로 하므로, 혼자 채굴할 때 하루 기대 블록 수는 288 × (자신의 해시레이트 ÷ 네트워크 해시레이트)입니다.

계산하기 쉬운 가상 수치를 사용해 보겠습니다. 50,000 H/s 네트워크에서 50 H/s 장비는 네트워크의 0.1%를 차지하며, 평균 하루 0.288블록, 약 3일 반마다 한 블록을 찾습니다. 이는 평균일 뿐입니다. 블록 발견은 무작위이므로 실제 간격은 훨씬 짧거나 길 수 있습니다.

같은 장비를 총 5,000 H/s인 풀에 연결하면 풀은 하루 약 28.8블록, 평균 50분마다 한 블록을 찾습니다. 장비가 풀 작업의 1%를 수행했으므로 각 블록의 1%를 받습니다. 기여한 작업은 같지만 보상이 하루 여러 번 작은 몫으로 들어옵니다. [Blocknet 풀 채굴과 솔로 채굴 비교](/blog/ko/pool-vs-solo-mining-blocknet/)에서는 더 큰 규모의 운영에 대해서도 계산합니다.

## 마이닝 풀은 어떻게 작동하나요?

모든 풀은 기본적으로 같은 과정을 반복합니다. bntpool.com에서는 다음과 같습니다.

1. **풀이 블록 템플릿을 만듭니다.** bntpool.com은 자체 Blocknet 노드를 운영하고 템플릿을 가져오므로, 채굴자는 노드를 직접 운영하거나 동기화할 필요가 없습니다.
2. **채굴자에게 작업을 보냅니다.** 채굴자는 풀이 작업을 전달하는 프로토콜인 Stratum을 통해 `stratum+tcp://bntpool.com:3333`에 연결합니다. 풀은 현재 템플릿에 기반한 작업을 각 연결에 보냅니다.
3. **채굴자는 해시를 계산하고 셰어를 제출합니다.** 셰어는 풀이 정한 더 쉬운 목표값을 만족하는 해시입니다. 셰어는 각 채굴자가 수행하는 작업량을 증명합니다.
4. **네트워크 목표값도 만족하는 셰어는 블록입니다.** 풀은 모든 셰어를 두 목표값에 대조합니다. 네트워크 조건도 충족하면 블록을 노드에 제출합니다.
5. **보상을 나누고 지급합니다.** 풀은 보상 방식에 따라 블록 보상을 나누고, 확정된 잔액이 최소 지급액을 넘으면 각 채굴자에게 몫을 보냅니다.

## 마이닝 풀의 셰어는 무엇인가요?

셰어는 실제 블록보다 낮은 기준을 통과한 해시입니다. 블록은 네트워크 목표값보다 낮은 해시가 필요하지만, 셰어는 훨씬 쉬운 풀의 셰어 목표값만 만족하면 됩니다. 대부분의 셰어는 블록이 되지 않지만, 각 채굴자의 해시 작업량을 꾸준히 보여 줍니다.

셰어에는 난이도에 따른 가중치가 적용됩니다. Blocknet에서 난이도 D는 목표값을 만족하기까지 평균 약 D번의 해시가 필요하다는 뜻이므로, 난이도 60인 셰어는 약 60번의 해시 작업을 나타냅니다. bntpool.com은 연결별로 셰어 난이도를 정하고 채굴 중 조정하며, 5분에 약 10셰어를 목표로 새 연결을 난이도 60에서 시작합니다. 빠른 서버에는 어려운 셰어, 노트북에는 쉬운 셰어를 주고 둘 다 실제 기여한 작업량을 인정받습니다. 풀은 장비별 난이도를 한 시간 동안 기억하므로 빠르게 재시작하면 이전 상태에서 이어집니다.

## 일반적인 마이닝 풀 보상 방식

보상 방식은 셰어를 수익으로 바꾸는 규칙입니다. 흔히 사용하는 방식은 다음과 같습니다.

| 방식 | 보상을 받는 대상 | 작동 방식 |
|---|---|---|
| PPLNS (pay per last N shares) | 풀이 찾은 블록 | 최근 구간에 제출된 셰어의 난이도에 비례해 각 블록의 보상을 분배 |
| PPS (pay per share) | 승인된 모든 셰어 | 블록 발견 여부와 관계없이 셰어의 기대 가치를 기준으로 고정 금액 지급 |
| 솔로 | 직접 찾은 블록 | 자신의 노드에서 채굴하고 발견한 각 블록의 전체 보상을 수령 |

**PPLNS**는 풀이 블록을 찾은 시점부터 과거를 살펴봅니다. bntpool.com에서 “최근 N개 셰어”는 6시간 구간입니다. 풀은 블록 발견 전 6시간 동안 승인된 모든 셰어의 난이도를 합산하고, 각 채굴자의 작업 비율과 같은 비율로 보상을 나눕니다. 셰어는 구간 안에 있는 동안 발견된 모든 블록에 반영되므로, 꾸준히 채굴하면 항상 전체 구간이 채워져 있고 재부팅해도 초기화되지 않습니다. [bntpool.com의 PPLNS 보상 방식](/blog/ko/how-pplns-payouts-work/)에서 분배 과정을 단계별로 설명합니다.

**PPS**는 셰어가 도착할 때마다 기대 가치에 따라 지급합니다. 셰어 난이도를 네트워크 난이도로 나누고 블록 보상을 곱한 값입니다. 풀 운영자가 블록 발견의 변동을 부담하며, 블록을 찾지 못하는 동안에도 자체 잔액으로 채굴자에게 지급합니다.

**솔로 채굴**은 풀을 거치지 않습니다. 자신의 노드가 템플릿을 만들고 발견한 블록의 전체 보상을 자신의 지갑에 지급합니다. 혼자서도 블록을 자주 찾을 만큼 큰 운영에 적합합니다. Seine은 두 방식을 모두 지원합니다. 기본적으로 bntpool.com에서 채굴하며, `./seine --mode daemon`을 사용하면 동기화된 자신의 Blocknet 노드에서 채굴합니다.

## 마이닝 풀을 선택할 때 무엇을 확인해야 하나요?

풀을 비교할 때 다음 항목이 보상 방식과 확인의 편의성을 결정합니다.

- **명확한 보상 방식.** 풀은 방식과 PPLNS 구간 같은 설정을 명시해야 합니다. bntpool.com은 [Get Started 페이지](/start)와 `https://bntpool.com/api/info`에 공개합니다.
- **승인 수와 최소 지급액.** 보상은 보통 블록이 체인에 충분히 깊이 들어갈 때까지 기다리며, 잔액이 최소 금액에 도달하면 지급됩니다. bntpool.com에서는 Blocknet의 코인베이스 성숙 기간에 맞춰 60블록 후 보상이 확정되고, 0.1 BNT 이상의 잔액이 자동 지급됩니다.
- **공개된 검증 가능한 수치.** 풀이 찾은 모든 블록과 보낸 모든 지급을 확인할 수 있어야 합니다. bntpool.com은 [블록](/blocks)과 [지급](/payouts) 페이지, 라운드별 작업 비율을 보여 주는 [운 페이지](/luck), 서비스 상태를 보여 주는 [상태 페이지](/status)를 제공합니다.
- **자신의 통계.** 주소를 조회해 해시레이트, 셰어, 잔액을 확인할 수 있어야 합니다. bntpool.com의 [통계 페이지](/stats)가 이 기능을 제공하며, [채굴기 모니터링 가이드](/blog/ko/track-your-miner-on-bntpool/)에서 각 카드를 설명합니다.
- **쉬운 설정.** 필요한 설정이 적을수록 빨리 채굴을 시작합니다. bntpool.com은 스레드, 커널, 메모리를 자동 조정하는 seine의 기본 풀이며, 전체 주소 대신 `@name` 같은 [Blocknet ID 이름](https://seineminer.com/ko/blog/blocknet-id-pay-by-name/)으로 로그인할 수 있습니다.
