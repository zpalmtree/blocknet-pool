# Farm proxy hint showcase

Run `npm --prefix frontend run showcase:farm-proxy` from the pool repository and open
http://localhost:5205/showcases/farm-proxy-hint/.

Renders the real My Stats banners with a synthetic account. States: `?state=hint`
(default), `with-update` (beside the update banner), `dismissed` and `none`; add
`&theme=light` or `&lang=ar` (RTL), `&lang=ja` and other locales.
