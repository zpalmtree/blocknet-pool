The pool in your language

The public pool interface uses the blog’s 20 languages, a shared saved preference, native-language switching offers, and a persistent language selector. Pool and blog links retain the selected language. Arabic uses a right-to-left layout.

Real application with synthetic API responses. Desktop: 1440 × 1000; mobile: 390 × 844. Captured through the configured Windows Playwright MCP and visually checked on October 25, 2026 (EDT). No live wallet or pool data. The admin interface and server diagnostic messages remain in English.

Source: base revision and exact source hashes. Captures cover all public routes, RTL, long labels, CJK, the language offer/menu, dark theme, empty, loading, error and disabled controls. Machine-assisted translations; no independent linguistic review.

Run the interactive fixture
npm --prefix frontend ci
npm --prefix frontend run showcase:languages
